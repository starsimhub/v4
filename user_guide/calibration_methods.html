Fitting methods

🧠0% 🤖100%

sim.fit() chooses a method that suits the model, so most fits don’t need to name one. This page is for choosing one yourself: what each method gives, what it needs, and what its settings are. Fitting a model covers the data, the parameters, and the goodness of fit, which are the same for every method.

Choosing a method

Method Gives The model Likelihood needed? Use it when Avoid it when
'nelder-mead' Best fit Any; default for an ODE with one or two parameters, or one with no gradients No Few parameters, or a model that can’t be differentiated There are many parameters, where it gets slow
'l-bfgs-b' Best fit ODE with gradients; default for three or more parameters No Many parameters of a deterministic model The model is stochastic
'optuna' Best fit Any; default for stochastic models and agents No Runs are noisy, or there is no better option You need a posterior, or a precise optimum (follow it with 'nelder-mead')
'if2' Maximum-likelihood best fit Stochastic compartmental Yes You want the maximum likelihood of a stochastic model, whose noise makes a local search unreliable A parameter has several values (by group, or a time series), or you need a posterior
'nuts' Posterior ODE with gradients Yes You need a posterior of a deterministic model; it’s the most efficient sampler here The model is stochastic or has no gradients
'pmcmc' Posterior Stochastic compartmental Yes You need a posterior of a stochastic model, with its process noise counted The model runs as agents, or is deterministic (use 'nuts')
'abc-smc' Approximate posterior Any, including agents No You need a posterior but have no likelihood, or the model runs as agents A likelihood-based posterior is possible, which is usually sharper

A “stochastic compartmental” model has solver='binomial', 'gillespie', or 'tau', and is one that the kernels run from start to finish, which sim.kernel_only() checks. If it doesn’t, 'if2' and 'pmcmc' raise an error that gives the reason.

Two more methods of scipy.optimize.minimize can also be named: 'powell' (no gradients) and 'slsqp' (gradients, when the sim has them). A list runs methods in turn: see below.

A setting that the method doesn’t take is an error, so a mistyped name can’t be ignored by accident.

The model

Every example fits the transmission rate of the same SIR model, with half of infections reported, to weekly cases drawn from a run with beta=0.5. The likelihood says how the reported cases vary around what the model gives, here Poisson.

import starsim as ss

beta = ss.par(0.3, bounds=[0.1, 1])
S, I, R = ss.states(3)
infection = S >> I @ beta*I
cases = ss.outcome(0.5*infection)
sir = ss.Disease(infection, I >> R @ ss.days(8), cases, init=dict(I=0.01), name='sir')

pars = dict(total_pop=10_000, unit='day', stop=60)
data = ss.Sim(sir, pars=dict(beta=0.5), solver='binomial', rand_seed=2, **pars).run().to_data('cases', resample='week')

deterministic = ss.Sim(sir, data=data, verbose=0, **pars)
stochastic = ss.Sim(sir, data=data, solver='binomial', verbose=0, **pars)
likelihood = dict(cases=ss.poisson())
Sim: sir, 10,000 people, as a stochastic compartmental model (chain binomial), days 0 to 60
  sir: R0 = 4, with 100 infectious at the start
  Done in 0.0078 s; sir: 9,709 infections; at most 4,114 infectious, on day 16

Best fits

SciPy: 'nelder-mead', 'l-bfgs-b', and others

These search from the best few points of a scan over the bounds. The gradient-based methods take their gradients from JAX (see Gradients). The fit has converged if the two best searches end at the same value.

Setting Default Meaning
scan 10 per parameter, at most 100 The number of points tried over the bounds
restarts 3 (1 for one parameter of a deterministic model) The number of searches, each from one of the best points that are apart
Others SciPy’s The method’s own options, e.g. maxiter=500; see scipy.optimize.show_options() 
fit = deterministic.fit(method='nelder-mead', scan=5, restarts=2, maxiter=200, verbose=False)
fit.pars
sc.obj(beta=0.489589109536295)

Optuna: 'optuna'

Optuna learns where to look from the scores so far, which suits noisy scores: each trial takes fresh random seeds, so the search averages over chance.

Setting Default Meaning
n_trials 100 The number of sets of values to try
n_workers 1 The number of processes running trials at once
storage None A file or database URL that keeps the trials, so a fit that stopped can be resumed
Others Optuna’s The keywords of study.optimize(), e.g. timeout=600 
fit = stochastic.fit(method='optuna', n_trials=50, verbose=False)
fit.pars
sc.obj(beta=0.5053382226999229)

Iterated filtering: 'if2'

Iterated filtering (IF2; Ionides et al. 2015) finds maximum-likelihood values of a stochastic model. It runs a particle filter many times. Each particle has its own parameter values, which take a small random step at each data point, and particles that fit the data well are kept along with their values. The steps shrink from one pass of the filter to the next, so the particles settle on the best values. It’s the method of the pomp package for R.

Each of several chains starts from its own point, and the fit has converged if they end within 2 of each other in log-likelihood. If they don’t, try more passes or more particles, as the message says.

Setting Default Meaning
particles 1000 The number of particles in each pass; more gives a less noisy likelihood
iterations 50 The number of passes of the filter in each chain
chains 4 The number of chains, each from its own start
sd 0.05 The first size of a random step, on the scale searched on (the logit of a value’s place between its bounds, of its log for wide bounds)
cooling 0.5 The share of the first step size that is left after 50 passes (pomp’s cooling.fraction.50) 
fit = stochastic.fit(method='if2', likelihood=likelihood, particles=100, iterations=25, verbose=False)
fit.summarize()
Fitted 1 parameter(s) by if2, with 101 evaluations
Negative log-likelihood: 4542 before, 44.7 after (the mean of 4 runs)
Converged: the 4 chains (from different starts, each of 25 passes with 100 particles) end within 0.35 of the best log-likelihood (-34.11)
spread_lower and spread_upper: the range of the chains' estimates, an indication of the uncertainty only, not an interval
par initial best low high spread_lower spread_upper
0 beta 0.3 0.506473 0.1 1.0 0.506473 0.512888

fit.table gives the range of the chains’ estimates. That shows how far the chains agree, and it is not a confidence interval; ss.fit.profile() gives one, and 'pmcmc' gives a posterior. Every data series needs a likelihood, and each fitted parameter needs to be a single value of one of the model’s rates.

fit.trials has the estimate and log-likelihood at each pass, which shows whether a chain has settled:

fit.trials.groupby('chain').tail(1)
beta objective chain iteration
25 0.508801 34.953387 0.0 25.0
50 0.510860 35.306978 1.0 25.0
75 0.512888 35.220140 2.0 25.0
100 0.506473 35.250510 3.0 25.0

Posteriors

A posterior uses each parameter’s prior= if it has one, and otherwise a uniform prior over its bounds. Its draws are in fit.samples, and fit.table adds the median, the 95% interval, and for chains R-hat and the effective sample size. Fit diagnostics covers how to read them. The examples below take few draws so that this page runs quickly, so they can report that they have not converged; a real fit should use the defaults or more.

NUTS: 'nuts'

The No-U-Turn sampler uses gradients to move through the posterior of a deterministic model. It needs JAX and BlackJAX.

Setting Default Meaning
draws 500 The number of draws kept from each chain
warmup 500 The number of warm-up steps of each chain
chains 4 The number of chains
scan 10 per parameter, at most 100 The number of points tried for the chains’ starts 
fit = deterministic.fit(method='nuts', likelihood=likelihood, draws=100, warmup=100, chains=2, verbose=False)
fit.table

  Compiling the gradient of the log-likelihood with JAX, estimated time: 0.5-5 s
  Compiling the NUTS sampler with JAX, estimated time: 1-10 s
par initial best low high median lower upper rhat ess

Particle MCMC: 'pmcmc'

Particle MCMC takes a random walk over the parameters, with the likelihood at each point estimated by a particle filter, so it includes the model’s process noise. Its draws are more correlated than those of NUTS, so it takes more of them.

Setting Default Meaning
draws 1000 The number of draws kept from each chain
warmup 1000 The number of warm-up draws of each chain
chains 4 The number of chains
particles Chosen in the warm-up The number of particles
parallel True Whether to run the chains at the same time
scan 10 per parameter, at most 100 The number of points tried for the start 
fit = stochastic.fit(method='pmcmc', likelihood=likelihood, draws=100, warmup=100, chains=2, particles=50, verbose=False)
fit.table
par initial best low high median lower upper rhat ess
0 beta 0.3 0.506383 0.1 1.0 0.505864 0.490255 0.523711 1.067935 31.179565

ABC-SMC: 'abc-smc'

Approximate Bayesian computation keeps the parameter values whose runs come closest to the data, by the goodness of fit, over generations with a shrinking tolerance. It needs no likelihood and works for agents, but each generation takes many runs, and the result is only as sharp as the final tolerance.

Setting Default Meaning
particles 200 The number of particles, which are the draws of the posterior
generations 8 The most generations to run
quantile 0.5 The quantile of the distances that sets the next tolerance
tolerance None The distance to stop at 
fit = stochastic.fit(method='abc-smc', particles=50, generations=4, verbose=False)
fit.table
par initial best low high median lower upper ess
0 beta 0.3 0.498262 0.1 1.0 0.522291 0.464767 0.568864 49.907081

Several methods in turn

With a list, each method starts from the best values of the one before, and the list stops at a method that doesn’t converge. A broad search followed by a local one is the usual pairing. A setting goes to the stages that take it, and an entry can be a dict to give one stage its own settings:

fit = deterministic.fit(method=['optuna', dict(method='nelder-mead', maxiter=100)], n_trials=30, verbose=False)
fit.pars
sc.obj(beta=0.48959051722230573)
