User guide

The user guide is organized by topic: each page covers one in full, to read through or to look up when you need it. The tutorials are the place to start; the user guide pages go further.

Introduction

  • What is Starsim?: what Starsim is for, and what it does
  • Starsim models: models and frameworks built with Starsim
  • Conceptual overview: sims, modules, states, transitions, and solvers in one page

Building models

  • Writing models: states, transitions, and rates, and checking what was built
  • Diseases: the built-in diseases and writing your own
  • Parameters: values, bounds, priors, and parameters that vary by group
  • Time: dates, durations, rates, time steps, and values that change over time
  • Stratification: splitting states by age, sex, risk, and more
  • Outcomes: reported cases, deaths, and other quantities derived from a model
  • Results: reading, summarizing, and exporting results
  • Plotting: plotting sims, results, and many runs
  • Custom modules: writing modules as code

Populations and data

  • People and agents: the population, as compartments or as agents
  • Demographics: births, deaths, migration, and pregnancy
  • Contact networks: who meets whom, from mixing pools to sexual networks
  • Population data: contact matrices and built-in data by country
  • Geography: places, and movement between them

Interventions and analyzers

  • Products: vaccines, treatments, and diagnostics
  • Interventions: delivering products, and changing parameters during a run
  • Analyzers: collecting results of your own
  • Connectors: linking modules, e.g. diseases that interact
  • Costs: the costs of interventions, and cost per outcome averted

Running models

  • Running sims: making and running a sim, and its settings
  • Scenarios: comparing scenarios, repeated runs, and uncertainty
  • Solvers and backends: ODEs, stochastic compartments, and agents, and how one is chosen
  • Branching and rescaling: large populations and small outbreaks
  • Profiling and debugging: finding what is slow or wrong, and common pitfalls
  • Deployment: running Starsim on clusters and in the cloud

Calibration

  • Fitting a model: fitting parameters to data
  • Fitting methods: each method, what it needs, its settings, and an example
  • Fit diagnostics: checking a fit
  • Parameter identification: which parameters the data can pin down
  • Gradients: derivatives of results with respect to parameters
  • Optimization: allocating a budget to get the best outcome

Model library

  • Modeling landscape: disease-modeling tools, and where Starsim fits
  • Library: diseases: HIV, cholera, Ebola, measles, and more, ready to use
  • Library: networks: household, spatial, and theoretical networks
  • Library: maternal-child health: fetal health, maternal infections, and neonatal outcomes
  • Conversion: import/export: bringing models in from other frameworks, and writing them out

Mechanics

  • Array indexing: agents, UIDs, and arrays
  • Distributions: random draws for agents
  • Random numbers: common random numbers, and comparing runs exactly
  • Nonstandard usage: agent-based models that are not about disease

Architecture

  • Overview: how Starsim works inside
  • Model declaration: how a model is held as data
  • Model execution: how a model becomes a run
  • Solvers and backends: the engines, and the kernels behind them
  • Transmission: routes, effects, and results
  • Randomness: random numbers, and fitting
  • Modules: what a module is, and how modules work together
TipRunning the user guide locally

Each page can be downloaded as a Jupyter notebook: look for the download button at the top of the page. Or clone the Starsim repository, install Starsim (pip install -e .), go to docs/user_guide, and open the pages in Jupyter (jupyter lab).
