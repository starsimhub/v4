transitions

transitions

States, transitions, and the expressions that drive them.

A model is a set of ss.State objects and the ss.Transition objects between them. A transition can be written with operators or in full, which build the same object:

S >> I @ 0.3 * I                                # Operators
ss.Transition(S, I, rate=0.3 * I)               # In full

The ss.graph.Graph class (in internals/graph.py) collects the states and transitions of one module, names them, fills in defaults (recording each guess), and checks them. The expressions are in ss.expressions, the values that vary (ss.by, ss.timeseries, ss.seasonal) in ss.parameters, how a model is shown in ss.display, and its stratifications in ss.dimensions.

Used with: agents and compartments; declared modules

Something a person can be in, or a count of something that is not people

A state is a compartment when the model runs as an ODE and a boolean array over agents when it runs as agents; the declaration is the same.

Parameters

Name Type Description Default
name str the name; if not given, taken from the keyword or the variable the state is assigned to None
init float the share of people who start in the state (1.0 is everyone); for a state that is not people, its starting amount None
init_n int instead, the number of people who start in the state None

E = ss.State(init_n=10)     # 10 people
V = ss.State(rel_sus=0.2, label='Vaccinated')
A = ss.State(keep_time=True) # Code reads mod.ti_A

A movement between states

Usually built with the operators (S >> I @ rate); ss.birth() and ss.death() also return an ss.Transition.

Parameters

Name Type Description Default
src State / list the source state, several states (a list, or a sum I + R), or ss.null for an inflow None
dst State / list the destination state, a list of states (branching), or ss.null for an outflow None
rate any a hazard: a number, ss.per, ss.prob, an expression of states and parameters, or a function; a transmission is a rate with the source of infection in it (rate=beta * I) None
dur any a dwell time: a duration or a distribution of durations (instead of rate); with an event in where=, the time after it that people move None
p float / list branch probability None
stages int number of sub-stages used to realize the dwell time None
where Cond / Event / func who it applies to: a condition (e.g. ppl.age > 30), as for ss.modify(where=); for everyone else its rate is 0. With no rate= or dur=, a trigger (see ss.on): people move as soon as a condition holds. An event moves the people it happens to (where=preg.delivery), or dur= after it (a time drawn for each person), as agents; joined to a condition with &, those who meet it None
move dict / StrainMove a change of level in a dimension as well as of state: the dimension, and the level people move to, or a pair of levels (e.g. move=dict(risk=('low', 'high')), which applies only to people at the first); or a change of strains (move=DS >> (DS, RIF), see ss.strains.Strain) None
increment str / dict a counter that goes up as well: its name, which adds 1 (increment='parity'), or a dict of the amount for each (increment=dict(parity=2) for twins, dict(doses=-1)); a counter is a dimension with integer levels, whose last level is open-ended None
after dur a minimum stay: nobody leaves by this transition until they have been in its source state this long (a rate applies from then on, and a dwell time starts then) None
acquisition bool whether it is an acquisition of the disease, which rel_sus, a product’s efficacy against acquisition, and ss.treat act on. If not given: a contact-mediated transition is, and so is any other transition out of the disease’s first state if none out of it is contact-mediated (an infection by a bite rate or an EIR) None
per str 'strain', for an event of a disease with strains (ss.Strains) in a state they share, with an outcome for each strain carried: with p=, each strain carried takes the first destination with its own probability (p= times the strain’s value for the transition, or p='<value>', the strains’ values of that name, with their values for the transition then multiplying its rate), and anyone left with a strain takes the second (or stays), carrying those left, e.g. cure by treatment None
alone bool with per='strain' and a rate: each strain carried has its own rate (the rate times its value), and the first to happen moves on alone (the others are dropped), e.g. one of two strains progressing False
name str the name; if not given, taken from the keyword or the variable it is assigned to None
label str a human-readable name None

Examples

S, I, R = ss.states(3)
infection = ss.Transition(S, I, rate=0.05 * I)
cure      = ss.Transition(I, S) # No driver: only by treatment
recovery  = ss.Transition(I, R, dur=ss.days(10))
maturing  = ss.Transition(J, A, rate=ss.perday(1), where=ppl.age > 1) # Only adults
failure   = ss.Transition(Tx, I, rate=ss.peryear(0.1), move=DS >> (DS, RIF)) # Treatment fails, and the strain acquires resistance (DS, RIF = strains)
twins     = ss.Transition(P, PP, dur=ss.months(9), p=0.02, increment=dict(parity=2)) # Parity goes up by 2
weaning   = ss.Transition(NB, W, rate=ss.perday(0.5), after=ss.days(21)) # At least 21 days old first, as EMULSION's duration
postpartum = ss.Transition(PP, NP, where=preg.delivery, dur=ss.months(6)) # Six months after each woman's own delivery
importation = ss.Transition(S, I, rate=ss.perday(1e-4), acquisition=True) # An infection from outside, alongside one by contact

birth

transitions.birth(
    state=None,
    rate=None,
    per=None,
    n=1,
    sex=None,
    name=None,
    label=None,

An inflow of people: at a crude (per-person) birth rate, e.g. ss.birth(S, rate=ss.peryear(0.02)); or driven by a flow, e.g. ss.birth(NP, per=preg.delivery, n=2), n children for each person who goes through the transition

With per=, as agents the children are made by the module that owns the transition, with parent set to the person who went through it, and placed in each declared module’s state given by its own ss.birth(per=...) of the same transition, or else its first state. Agents only, for now.

Births of the whole population go in ss.Sim(demographics=[...]), where they are declared once for every disease’s people and run under every solver; births into one disease’s state go in the disease.

Parameters

Name Type Description Default
state State the state people are born into (default: the disease’s first state; in demographics=, each disease’s) None
rate any the birth rate per person per unit time, e.g. ss.peryear(0.03); for the births of everyone (no state), a bare number (or a time series of them) is read as ss.Births reads a number, per year and, if above 1, per 1,000 people (30 is ss.peryear(0.03)); into a state, it is in the model’s unit, as any bare number in a disease None
per Transition instead of a rate, the transition whose flow drives the births None
n int / Dist the number of children each time: a number, or a distribution (drawn for each parent) 1
sex float / Dist the chance a child is female (default: as for anyone added) None
name str the name of the transition None
label str a human-readable name None

Examples

ss.Sim(sir, demographics=[ss.birth(rate=ss.peryear(0.02)), ss.death(rate=ss.peryear(0.01))])
ss.Sim(sir, demographics=[ss.birth(rate=20), ss.death(rate=10)]) # The same: per 1,000 people per year

move

transitions.move(*args, p=None, n=None, uids=None, where=None)

Move people between states of a declared disease from code, the same way under every solver

A one-off move along no transition (as ss.Delivery(move=I >> R) is for a declared intervention), so people are moved and never made or lost: the number of people stays the same in every disease. A count that is not people (ss.State(people=False), e.g. mosquitoes) moves the same way, and also from and to outside the model (ss.null), which for people is a birth or a death, and is declared. Also disease.move(...), the same with the disease given.

Parameters

Name Type Description Default
args in any order, told apart by what they are: the state (or a list of states) to move people from and the state to move them to, as the code sees them at run time (sir.I) or by name ('I'), the source first; the disease, which is enough to say where they come from (any of its states of people); and the agents to move (ss.uids), as uids= ()
p float the share of the people in the source to move, in each group (by default, everyone) None
n float instead, the number of people to move, shared among the groups and states in proportion to who is in them None
uids uids only these agents (those of them in the source), which needs agents; with p= or n=, a share or number of them None
where Cond / State only the people for whom a condition holds (e.g. ss.ppl.age < 15, or a group), under every solver; with p= or n=, a share or number of them None

Returns

Name Type Description
The number of people moved

Examples::

ss.move(sir.I, sir.R, p=0.5) # Cure half of those infectious
ss.move(sir.S, sir.I, n=5) # Five susceptible people become infectious
ss.move(sir.S, sir.R, p=0.8, where=ss.ppl.age < 5) # Protect 80% of the susceptible children under 5
sir.move(uids, sir.R) # These agents, from wherever they are (also ss.move(sir, uids, sir.R), or sir.move(uids, 'R'))
self.move(self.I, self.R, uids=uids) # In a disease's own code: these agents, if they are infectious
ss.move(mosq.Sv, ss.null, p=0.1) # A tenth of the mosquitoes die

pars

transitions.pars(defaults, **kwargs)

Create several parameters at once, from defaults and the values given, as a class’s declared parameters are made

For a disease whose states and transitions depend on its options, and so are made in __init__() rather than declared on the class (e.g. beta = ss.par(...), as ss.SIR does). Each parameter is an ss.par named after its key, so it can be fitted or set by name (ss.Sim(pars=...)). A value given takes the default’s bounds and description unless it has its own; a bare number for a typed default keeps its unit (e.g. 2 for a default of ss.peryear(1) is 2 per year); a default of None is an optional parameter, None unless given. A name that is not a default is an error.

Parameters

Name Type Description Default
defaults dict the default of each parameter: a value, or an ss.par (with bounds, say) required
kwargs dict the values given, e.g. the keywords of the disease’s __init__() {}

Returns an sc.obj of the parameters, by name.

Examples

defaults = dict(beta=ss.par(ss.peryear(2), bounds=[ss.peryear(0.5), ss.peryear(5)]), dur=ss.years(2), relapse=None)
p = ss.pars(defaults, beta=3) # beta is 3 per year, with the default's bounds
S, I, R = ss.states('S I R')
transitions = [S >> I @ p.beta*I, I >> R @ p.dur] + ([R >> I @ p.relapse] if p.relapse is not None else [])
