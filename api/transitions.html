transitions

transitions

States, transitions, and the expressions that drive them.

A model is a set of ss.State objects and the ss.Transition objects between them. A transition can be written with operators or in full, which build the same object:

S >> I @ 0.3 * I                                # Operators
ss.Transition(S, I, rate=0.3 * I)               # In full

The ss.graph.Graph class (in internals/graph.py) collects the states and transitions of one module, names them, fills in defaults (recording each guess), and checks them. The expressions are in ss.expressions, the values that vary (ss.by, ss.timeseries, ss.seasonal) in ss.parameters, how a model is shown in ss.display, and its stratifications in ss.dimensions.

Used with: agents and compartments; declared modules

noise float / par random variation of the rate from step to step (see below), for data that vary more than chance alone explains; sigma, which can be fitted (noise=ss.par(0.1, bounds=[0, 0.3])) None
acquisition bool whether it is an acquisition of the disease, which rel_sus, a product’s efficacy against acquisition, and ss.treat act on. If not given: a contact-mediated transition is, and so is any other transition out of the disease’s first state if none out of it is contact-mediated (an infection by a bite rate or an EIR) None
per_strain str for a disease with strains (ss.Strains) in a state they share, an outcome for each strain carried: 'each' or 'first' (see below) False
name str the name; if not given, taken from the keyword or the variable it is assigned to None
label str a human-readable name None

Noise. noise= is sigma of gamma white noise (Bretó et al. 2009; pomp’s rgammawn): the chain binomial multiplies the rate, in each substep of length h, by a gamma draw with mean 1 and variance sigma²/h, for each group (and each particle of a filter). Sigma is in the square root of the sim’s unit (0.0878 in He et al.’s model, in years). Tau-leaping draws it for each leap (h its length), and agents once a step for each group (h the step); the ODE leaves it out (its mean), and the exact solver ('gillespie') refuses it.

Strains. With per_strain=:

  • 'each': with a split, each strain carried takes the first destination with its own probability (the first destination’s probability times the strain’s value for the transition, or '<value>', the strains’ values of that name, with their values for the transition then multiplying its rate), and anyone left with a strain takes the second (or stays), carrying those left; e.g. cure by treatment
  • 'first': with a rate, each strain carried has its own rate (the rate times its value), and the first to happen moves on as the only strain carried (the others are dropped); e.g. one of two strains progressing

Examples

S, I, R = ss.states(3)
infection = ss.Transition(S, I, rate=0.05 * I)
cure      = ss.Transition(I, S, rate=0) # A rate of 0: only treatment moves people along it
recovery  = ss.Transition(I, R, dur=ss.days(10))
maturing  = ss.Transition(J, A, rate=ss.perday(1), who=ss.person.age > 1) # Only adults
failure   = ss.Transition(Tx, I, rate=ss.peryear(0.1), move=DS >> (DS, RIF)) # Treatment fails, and the strain acquires resistance (DS, RIF = strains)
twins     = ss.Transition(P, PP, dur=ss.months(9), p=0.02, increment=dict(parity=2)) # Parity goes up by 2
weaning   = ss.Transition(NB, W, rate=ss.perday(0.5), min_stay=ss.days(21)) # At least 21 days old first, as EMULSION's duration
infection = ss.Transition(S, E, rate=beta*I, noise=0.0878) # Infection whose rate varies at random from step to step (He et al. 2010)
postpartum = ss.Transition(PP, NP, when=ss.on(preg.delivery, delay=ss.months(6))) # Six months after each woman's own delivery
importation = ss.Transition(S, I, rate=ss.perday(1e-4), acquisition=True) # An infection from outside, alongside one by contact

An inflow of people: at a crude (per-person) birth rate, e.g. ss.birth(S, rate=ss.peryear(0.02)); or driven by a flow, e.g. ss.birth(NP, when=preg.delivery, children=2), children for each person who goes through the transition

migration

transitions.migration(rate=None, rate_per=None, name=None)

Net migration of everyone, at a rate per person of either sign: arrivals less departures, as the UN gives it, e.g. ss.migration(rate='Albania')

A positive rate is arrivals, in proportion to the population (as agents, at the population’s ages: ss.immigration()); a negative one is departures (ss.emigration()). Both go in ss.Sim(demographics=[...]), and run under every solver. Since the rates are net, they say nothing about who migrates: as agents, those who leave are chosen at random.

The rates are read as those of ss.Births and ss.Deaths are (see ss.demographics.rate_per_of()): a bare number (per year) or a typed rate is per 1,000 people if it is above 1 per year (the median of the sizes, for a time series), else per person; rate_per= says which. A place’s UN rates are per 1,000.

Parameters

Name Type Description Default
rate str / float / rate / timeseries a place by name, for its UN crude net migration rates (by year, every ten years, linearly interpolated); a bare number per year or a typed rate (e.g. -5 or ss.peryear(-5) per 1,000, or ss.peryear(-0.005) per person), or a time series of either None
rate_per float how many people the rates are per: 1000 or 1 (per person); by default, read from their size None
name str the name of the transitions (by default immigration and emigration) None

Returns

Name Type Description
A list of the transitions: the arrivals, the departures, or both (if the rate changes sign)

Examples

ss.Sim(demographics=[ss.birth(rate=20), ss.death(rate=10), ss.migration(rate=3)]) # 3 more people per 1,000 a year
ss.migration(rate=-0.5, rate_per=1000) # 0.5 fewer per 1,000 a year: below 1, so rate_per= says it is per 1,000

move

transitions.move(*args, p=None, n=None, uids=None, who=None)

Move people between states of a declared disease from code, the same way under every solver

A one-off move along no transition (as ss.Event(I >> R) is for a declared one). People can also be moved into the model and out of it: to ss.dead (they die) or ss.outside (they leave), and from ss.unborn (they are born) or ss.outside (they arrive), with n=. Every disease has the same people, so people who die or leave leave every disease, and people added are in each other disease’s first state, under every solver: as agents, they are agents who die or are made (a death happens at the end of the step, as people.request_death() does); in a compartmental run, the diseases tracked jointly lose and gain the same people, and a disease run apart loses them from its states in proportion, in each group, as it has them (it runs apart since its states do not depend on the others’). People added are placed in groups as declared births (ss.unborn) or arrivals (ss.outside) are. A count that is not people (ss.State(people=False), e.g. mosquitoes) moves the same way. Also disease.move(...), the same with the disease given.

Parameters

Name Type Description Default
args in any order, told apart by what they are: a move written with the states (sir.I >> sir.R), or the state (or a list of states) to move people from and the state to move them to, as the code sees them at run time (sir.I) or by name ('I'), the source first; the disease, which is enough to say where they come from (any of its states of people); and the agents to move (ss.uids), as uids=
p float the share of the people in the source to move, in each group (by default, everyone) None
n float instead, the number of people to move, shared among the groups and states in proportion to who is in them None
uids uids only these agents (those of them in the source), which needs agents; with p= or n=, a share or number of them None
who Cond / State / func / str only the people for whom a condition holds (e.g. ss.person.age < 15, a group, or a state by its path, 'sir.I'), under every solver; with p= or n=, a share or number of them None

Returns

Name Type Description
The number of people moved

Examples

ss.move(sir.I, sir.R, p=0.5) # Cure half of those infectious
ss.move(sir.I >> sir.R, p=0.5) # The same, written as a move, as for ss.Event()
ss.move(sir.S, sir.I, n=5) # Five susceptible people become infectious
ss.move(sir.S, sir.R, p=0.8, who=ss.person.age < 5) # Protect 80% of the susceptible children under 5
sir.move(uids, sir.R) # These agents, from wherever they are (also ss.move(sir, uids, sir.R), or sir.move(uids, 'R'))

sir.move(uids, ss.dead) # These agents die, whatever their state

pars

transitions.pars(defaults, **kwargs)

Create several parameters at once, from defaults and the values given, as a class’s declared parameters are made

For a disease whose states and transitions depend on its options, and so are made in __init__() rather than declared on the class (e.g. beta = ss.par(...), as ss.SIR does). Each parameter is an ss.par named after its key, so it can be fitted or set by name (ss.Sim(pars=...)). A value given takes the default’s bounds and description unless it has its own; a bare number for a typed default keeps its unit (e.g. 2 for a default of ss.peryear(1) is 2 per year); a default of None is an optional parameter, None unless given. A name that is not a default is an error.

Parameters

Name Type Description Default
defaults dict the default of each parameter: a value, or an ss.par (with bounds, say) required
kwargs dict the values given, e.g. the keywords of the disease’s __init__()

Returns an sc.obj of the parameters, by name.

Examples

defaults = dict(beta=ss.par(ss.peryear(2), bounds=[ss.peryear(0.5), ss.peryear(5)]), dur=ss.years(2), relapse=None)
p = ss.pars(defaults, beta=3) # beta is 3 per year, with the default's bounds
S, I, R = ss.states('S I R')
transitions = [S >> I @ p.beta*I, I >> R @ p.dur] + ([R >> I @ p.relapse] if p.relapse is not None else [])

states

transitions.states(arg=None, infected=False, include_sum=False, **kwargs)

Create several states at once

Parameters

Name Type Description Default
arg int / str the number of states, which take their names from the variables they are assigned to; or a string of names (e.g. 'S I R'), which are used directly None
infected bool / str / list which of them are infected (see ss.State): all of them (True); some, by name, with names given up front ('E I'); or some, by position, with a number of states ([1, 2], or range(1, 6)) False
