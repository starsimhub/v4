internals.dates

internals.dates

Dates: ss.date, an array of them (ss.DateArray), and calendar durations (ss.datedur)

They give every module one way to work with calendar time, in calendar dates or in decimal years.

Used with: agents and compartments; declared and coded modules

datedur

internals.dates.datedur(value=None, **kwargs)

A calendar duration, e.g. ss.datedur(months=1): a thin wrapper of pd.DateOffset

Added to a date, it follows the calendar, so a month from 31 January is the end of February and a year from 1 March 2020 is 1 March 2021; dt=ss.datedur(months=1) steps a sim by calendar months. It takes whole numbers of years, months, weeks, and days (as keywords), or one of: a pd.DateOffset, a dateutil.relativedelta, a number of years, or a duration in one of these units (e.g. ss.days(7)). As a number (.years, .days, or divided by another duration) it is approximate, as other durations are: a year is 365 days, and a month a twelfth of a year. The time between two dates (date - date) is ss.days, not a datedur.

Examples

ss.date('2020-01-31') + ss.datedur(months=1) # 2020-02-29
ss.datedur(years=1)/ss.datedur(months=1) # 12

Attributes

Name Description
days The approximate number of days
kwds The number of each calendar unit, e.g. dict(months=1)
months The approximate number of months
weeks The approximate number of weeks
years The approximate number of years, e.g. ss.datedur(months=6).years is 0.5

Methods

Name Description
replace Return an ss.dur with the supplied value; see TimePar.replace()
to As a plain duration in a unit (e.g. ‘year’ or ss.years), approximately, as other durations are, e.g. ss.datedur(months=6).to(‘years’) is ss.years(0.5)
to_dur As a plain duration, in the finest unit it has, e.g. ss.datedur(years=1, days=10).to_dur() = ss.days(375)
