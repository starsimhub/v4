run

run

Running many sims: ss.parallel() and ss.MultiSim

These exist so that a model can be run many times, across seeds, parameter values, or scenarios, with the results gathered in one place for comparing and plotting.

Used with: agents and compartments; declared and coded modules

Branching

run.Branching(runs)

What came of the runs of a branching process together (msim.branching): see sim.branching for one run

Attributes

Name Type Description
sizes array the people infected in each run, the seeds included
outcomes array each run’s outcome: 'extinct', 'stopped' (by until=), or 'ongoing'
p_extinct float the share of the runs that went extinct, and p_extinct_ci its 95% interval (Wilson’s)
lengths array as agents, the most generations of each run’s chain
offspring array as agents, the number each person infected, of everyone infected long enough before the end that their offspring are all counted (see sim.branching); only if no run was stopped by until=, since where a run stops depends on its offspring
R, k (float as agents, the mean of the offspring and their dispersion, as a negative binomial fitted by maximum likelihood (k is infinite for offspring no more variable than a Poisson’s); None if a run was stopped by until=, so to estimate them, run for a fixed dur instead

Example

sir = ss.SIR(beta=ss.perday(0.3), dur_inf=ss.days(10), init_n=dict(I=1))
sim = ss.Sim(diseases=sir, total_pop=1e6, branching=True, solver='gillespie', unit='day', dur=365)
msim = sim.run(n_runs=200, until=sir.I.n + sir.R.n >= 200)
msim.branching.p_extinct # About 1/R0 = 1/3
msim.branching.plot()

MultiSim

run.MultiSim(
    sims=None,
    base_sim=None,
    label=None,
    n_runs=None,
    pars=None,
    priors=False,
    initialize=False,
    inplace=True,
    debug=False,
    **kwargs,
)

The runs of one or more sims: every result of the sims with a run axis first, and the sims that were run

Made and run by ss.parallel(), the way to run many sims (or by sim.run(n_runs=...), a shortcut for running one sim many times). Making a MultiSim and calling msim.run() does the same.

Parameters

Name Type Description Default
sims Sim / list a single sim, a list/tuple of sims, or another MultiSim (or list of MultiSims) None
base_sim Sim the sim used for shared properties; if not supplied, the first of the sims provided None
label str the name of the multisim None
n_runs int the number of runs of each sim, each with its own seed (by default, 4 for a single sim given as sims, otherwise 1) None
pars dict / list sets of values of parameters to run each sim with; see ss.parallel() None
priors bool / dict draw n_runs sets of values from the priors of the parameters, or the draws to run; see ss.parallel() False
initialize bool whether to make and initialize the sim of each run now (otherwise, when it is run) False
inplace bool whether to update sims that are run as they are (with no n_runs or pars) with their results (default True) True
debug bool if True, run in serial False
kwargs dict how to run the sims: parallel (default True), n_cpus, par_args (passed to sc.Parallel()), shrink, verbose, and run_args (passed to sim.run()) {}

By default (verbose not given: the sims’ own verbose, if they share one, else ss.options.verbose) the runs print nothing of their own, and the MultiSim shows their progress: nothing for runs that are done within a second, a bar for each run if there are up to 10 that each take more than 10 seconds, and otherwise one bar with the number of runs done (to a file, a line every tenth); then a line on what was run.

Once run, a MultiSim has:

  • results: every result with a run axis first (see ss.Result), e.g. msim.results.sir.I.quantiles();
  • runs: one row per run, with its scenario (the label of its sim), the values of any parameters swept or drawn, and its seed (rand_seed);
  • sims: the sims that were run (for runs restarted from one compartmental sim, that sim, as it was after its last run).

len(msim) is the number of runs.

A subclass changes the sim of each run by overriding make_run(), and can take options of its own for it by adding them to run_options (see the last example).

Examples

import starsim as ss

s1 = ss.Sim(networks='random', diseases=ss.SIS(beta=0.02), label='Low transmission')
s2 = ss.Sim(networks='random', diseases=ss.SIS(beta=0.05), label='High transmission')
msim = ss.parallel(s1, s2, n_runs=5)
msim.plot() # The median and a 95% interval of each scenario
msim.results.sis.prevalence.select(scenario='Low transmission').median()

class NoisyMultiSim(ss.MultiSim): # Each run with its own beta, drawn around 0.05
    run_options = ss.MultiSim.run_options + ['noise']

    def make_run(self, sim, values, seed, noise=0.1):
        beta = 0.05*np.exp(noise*np.random.default_rng(seed).normal())
        return super().make_run(sim, dict(values or {}, beta=beta), seed)

msim = NoisyMultiSim(s1, n_runs=10, noise=0.2).run()

combine
run.MultiSim.combine()

Combine the sims into a single sim, whose results are those of one population made of all of them, e.g. to treat several smaller sims as one larger population

Only the output is combined. Results that scale with population size (res.scale=True, e.g. counts) are summed; other results (e.g. prevalence) are averaged, weighted by each sim’s total_pop. The population sizes (n_agents and total_pop) are summed, and pop_scale is updated to match. The people are not joined: the combined sim keeps the people (if any) of the first sim, so it is not a larger population of agents that interact, and cannot be run again as one. To keep the runs as runs, see ss.MultiSim.merge().

Returns
Name Type Description
The combined sim
Examples
msim = ss.MultiSim(ss.Sim(n_agents=1e3, diseases='sis', networks='random'), n_runs=4)
msim.run()
sim = msim.combine() # Equivalent to a single sim with n_agents=4e3
sim.plot()

summarize
run.MultiSim.summarize(key=None, interval=0.95, how=None, baseline=None)

A table of each result over the whole of each run, across the runs: the median, an interval, the mean, and the standard deviation

Each result is first summarized over each run by its summarize_by (see sim.summarize()): a flow (e.g. infections) by its total, a stock (e.g. the number recovered) by its final value, and a ratio (e.g. prevalence) by its mean. Results that are 0 throughout are kept, so the tables of different runs (and of sim.summarize()) line up row for row.

Parameters
Name Type Description Default
key str if given, only this result (e.g. 'sir_infection' or 'sir.infection'), as msim.summarize().loc[key]: its row (or a row per scenario, if there are several) None
interval float the share of runs the interval holds (default 0.95: from the 2.5th to the 97.5th percentile), as msim.plot() shows 0.95
how str / dict how to summarize each result over each run: ‘mean’, ‘median’, ‘sum’, ‘last’, ‘max’, ‘min’, or a function, or a dict of these by result key, as for sim.summarize() None
baseline str the label of a scenario to compare with: each other scenario’s difference from it, run by run (the runs are paired by position, as in msim.diff()), so the interval is of the paired differences None
Returns
Name Type Description
A dataframe with a row for each result (and scenario, if there are several), and the columns median, low, high, mean, and std
(or value, if each scenario was run once); with key, the rows of that result
Example
msim = sim.run(n_runs=20)
msim.summarize()                     # Every result
msim.summarize('sir_infection')      # The total infections
msim.summarize(how=dict(sir_I='max')) # The peak number infectious in each run, over the runs
msim.summarize(baseline='No intervention') # Each scenario's difference from the baseline, e.g. the infections averted (negative)

RestartedSims

parallel

run.parallel(*args, n_runs=None, pars=None, priors=False, **kwargs)

Run many sims: different sims, each sim many times with its own seed, or with sets of values of its parameters

This is the one way to run many sims; sim.run(n_runs=...) is a shortcut for running one sim many times. Every way of running ends in the same results: each result with a run axis first.

Parameters

Name Type Description Default
args list the sims to run, or a dict of them by label (e.g. {'No intervention': s1, 'Vaccine': s2}) ()
n_runs int if provided, run each sim this many times, each with its own seed (the sim’s seed, plus 1, 2, …) None
pars dict / list sets of values of parameters to run each sim with: a dict with a list of values for each parameter (dict(beta=[0.2, 0.3])), or a list of dicts; each set is run n_runs times (default 1), with the same seeds for every set, and each set is a scenario of its own; the values are in msim.runs (and can be selected, e.g. res.select(beta=0.2)), with each run’s rand_seed. Seeds can be given too, e.g. pars=dict(rand_seed=[1, 5, 9]), as runs of the scenario rather than scenarios None
priors bool / dict draw n_runs sets of values from the priors of the parameters (ss.par(prior=...), or uniform over its bounds), one run each: a projection that carries the uncertainty in the values; or the draws themselves, as for pars= (e.g. from a posterior, as fit.project() passes them). Unlike a sweep with pars=, the draws are runs of their sim’s scenario, each with a seed of its own (the sim’s seed, plus 1, 2, …), so quantiles over a scenario’s runs include both the draws and chance False
kwargs dict sims passed as keywords are labeled with the keyword, e.g. ss.parallel(baseline=s1, vaccine=s2); everything else is passed to ss.MultiSim(), e.g. parallel=False, n_cpus, shrink {}

Returns

Name Type Description
A run MultiSim. Each result is available across the runs, with the label of each sim as its scenario,
e.g. msim.results.sir.I.quantiles([0.025, 0.5, 0.975]).

Examples

s1 = ss.Sim(n_agents=1000, label='Small', diseases='sis', networks='random')
s2 = ss.Sim(n_agents=2000, label='Large', diseases='sis', networks='random')
ss.parallel(s1, s2).plot()
msim = ss.parallel([s1, s2], shrink=False)
msim = ss.parallel(s1, n_runs=10) # Ten runs of one sim (also sim.run(n_runs=10))
msim = ss.parallel({'Baseline': s1, 'With vaccine': s2}, n_runs=10) # Two scenarios; see msim.diff('Baseline')
msim = ss.parallel(sim, pars=dict(beta=np.linspace(0.1, 0.5, 100))) # One run with each value of beta

restart_runs

run.restart_runs(sims, n_runs, pars=None, draws=False)

Run each sim a number of times, each with its own seed, by building it once and restarting it

Only for sims that are nothing but compartments (see ss.Sim.restart()), where this is many times faster than running copies. Returns None if any of the sims is not. Otherwise returns the sim of each run (RestartedSims, which makes each one when it is asked for), the results of every run (ss.run.MultiResults), and a dataframe of the runs.

With pars= (see ss.parallel()), each set of values is run n_runs times (as runs of their sim’s scenario if they are draws). An ODE with at least jax_runs runs (and JAX installed) takes them all in one call to JAX (see ss.gradients), which is faster than the kernels for that many.

Run each of a list of sims, in parallel using multiprocessing (or, with parallel=False, in a loop)
