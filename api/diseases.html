diseases

diseases

Diseases: the base class (ss.Disease), diseases with transmission written as code (ss.Infection), and the textbook models (ss.SIR, ss.SIS, ss.SEIR)

ss.Disease exists so that one class can hold a disease declared from states and transitions, written as code, or both. A declared disease runs with any solver; ss.Infection and other code that works on individual agents runs as agents.

Used with: agents and compartments; declared and coded modules

Disease

diseases.Disease(
    *args,
    pars=None,
    strains=None,
    stratify=None,
    _names=None,
    **kwargs,
)

A disease: states people are in and the transitions between them (declared), code, or both

Declared from its states and transitions, no methods need to be defined, and the disease can be run with any solver (see ss.Sim):

S, I, R = ss.states(3)
sir = ss.Disease(
    infection = S >> I @ 0.3 * I,
    recovery  = ss.Transition(I, R, dur=10),
    init_prev = 0.01,
)

The same disease can be declared in a class body (the class form), which can also add behavior by defining methods; ss.SIR, ss.SIS, and ss.SEIR are written this way.

A disease can also be written as code: a subclass that declares nothing, defines its per-agent arrays (define_states()), and changes them in its own step_state() and step(); it runs as agents. One class can mix the two, e.g. a declared natural history and a coded array that its step() updates after super().step() has taken the declared transitions. Each lifecycle method runs the declared part through the disease’s engine (which, for a disease that declares nothing, has nothing to run), so an override calls super() as for any module. ss.Infection adds transmission written as code.

Note: CRN safe as agents.

Examples

# Operator form: declare the states, then the transitions
S, I, R   = ss.states(3)
infection = S >> I @ 0.3 * I
recovery  = I >> R @ ss.days(10)
sir = ss.Disease(infection, recovery, init_prev=0.01)
ss.Sim(sir, stop=100).run().plot()

# Class form: for when there is behavior that is not a transition
class SIR(ss.Disease):
    S, I, R   = ss.states(3)
    infection = S >> I @ 0.3 * I
    recovery  = I >> R @ ss.days(10)

# Written as code: a disease that is not transmitted
class Anemia(ss.Disease):
    def __init__(self, **kwargs):
        super().__init__()
        self.define_pars(p_onset=ss.bernoulli(0.01))
        self.update_pars(**kwargs)
        self.define_states(ss.BoolState('anemic', label='Anemic'))

    def step_state(self):
        self.anemic[self.pars.p_onset.filter()] = True

R0
diseases.Disease.R0(matrix=False)

The basic reproduction number, from the next-generation matrix at the disease-free state

By definition it is in a population with no immunity: everyone is taken to be in the first state (e.g. S), each group keeping its size, whoever starts immune (init=dict(R=0.9)). The reproduction number at the start, with that immunity, is in the line a run prints as it starts, when it differs (R0 = 15.2 (R = 1.52 at the start, with 10% susceptible)).

The model is laid out as an ODE: if the disease is in a sim, a copy of that sim is made with solver='ode', with its mixing and stratification; otherwise a sim with the disease alone, under homogeneous mixing, with the default number of people. Values that vary in time are taken at the start. A sim runs a copy of the disease it is given, so the R0 of a sim’s model is sim.diseases.<name>.R0(); this matters where a count is a number rather than a share of the people (mosquitoes per person).

This is the largest eigenvalue of the next-generation matrix. Where infection passes through a vector (people infect mosquitoes, which infect people), each passage is a generation, so R0 is the square root of the classical Ross–Macdonald value. Shedding into a reservoir that is a count (such as water) is not an infection, so there R0 is the number of people infected through the reservoir by one person.

Parameters
Name Type Description Default
matrix bool if True, return the next-generation matrix (over the infected compartments of every group) rather than its largest eigenvalue False

Example:

S, I, R = ss.states(3)
sir = ss.Disease(infection=S >> I @ 0.3*I, recovery=ss.Transition(I, R, dur=10))
sir.R0() # 3.0

current_value
diseases.Disease.current_value(key, uids=None)

rel_sus or rel_trans (key) of each agent with the modifiers and products active on it applied (ss.modify(dis.rel_sus, ...)), as agents: what transmission uses, whereas reading dis.rel_sus gives the base values, which a modifier never changes. Or a parameter (key is its name) with the modifiers active on it, in its own type, declared or written as code: one value, or one for each agent if they differ between agents.

A disease written as code that reads one in its own code (other than in an ss.Infection’s transmission) says so in its class, allow_modifiers = ('rel_sus',), so that modifiers of it are applied rather than refused. A parameter it doesn’t say this of is read from self.pars with the modifiers applied, which is one value, so a modifier of it can’t differ between agents.

Parameters
Name Type Description Default
key str ‘rel_sus’, ‘rel_trans’, or the name of a parameter required
uids uids the agents to give the values of (default: an array of every agent, by UID) None

Example::

sim.diseases.sir.current_value('rel_sus') # With a vaccine's efficacy applied

class Diabetes(ss.Disease):
    allow_modifiers = ('rel_sus',) # ss.modify(diabetes.rel_sus, ...) scales its onset
    def step(self):
        uids = self.at_risk.uids
        onset = self.pars.p_onset.rvs(uids)*self.current_value('rel_sus', uids) # ...

diseases.Disease.define_transitions(*args, overwrite=False, **kwargs)

Define its transitions, in its __init__(), after its states

For a declared disease whose structure depends on its arguments, so that it cannot be written in a class body: the states (define_states()), transitions, and results (define_results()) are built together once its __init__() has finished. Each is an attribute at once (self.infection).

Parameters

Examples
class SIRS(ss.Disease):
    def __init__(self, waning=True, **kwargs):
        super().__init__(init_prev=0.01, **kwargs)
        self.define_states(ss.states('S I R'))
        beta = ss.par(0.3)
        self.define_transitions(
            infection = self.S >> self.I @ beta*self.I,
            recovery  = self.I >> self.R @ ss.days(10),
        )
        if waning:
            self.define_transitions(waning=self.R >> self.S @ ss.days(100))

step_die
diseases.Disease.step_die(uids)

Carry out state changes upon death: the agents who died leave every declared state (as agents)

This function is triggered after deaths are resolved, and before analyzers are run. See ssl.AgentSIR for a typical use case - deaths are requested as an autonomous update, to take effect after transmission on the same timestep. State changes that occur upon death (e.g., clearing an infected flag) are executed in this function. That also allows an intervention to avert a death scheduled on the same timestep, without having to undo any state changes that have already been applied (because they only run via this function if the death actually occurs).

Unlike other methods during the integration loop, this method is not called directly by the sim; instead, it is called by people.step_die(), which reconciles the UIDs of the agents who will die.

Infection

diseases.Infection(pars=None, strains=None, **kwargs)

A disease with transmission written as code

An ss.Disease that adds network-based transmission with directional beta values (transmit(), transmit_route()), the susceptible and infected states, the attributes that other modules act on (rel_sus, rel_trans), set_prognoses() for the people infected, and the prevalence and infection results. The rest of the disease is written as for any other module: its own per-agent states (define_states()) and how they change (step_state(), set_prognoses()), so it can hold anything an agent can have: a CD4 count, an immunity level that wanes, a time since infection. It runs as agents. A disease with no beta (such as ssl.NCD) is not transmitted; one that has no use for these states at all is a plain ss.Disease.

An infection in a step happens at its end, so a course scheduled from it starts at the next step: schedule a move dur steps after an infection at self.ti + 1 + dur, in an ss.TimeArr, and take it when due() (as in the example below). Each case is then infectious for dur steps on average, as a declared disease’s is; the seeds are dated at the start (self.ti is 0), the end of the step before the first, so they are too.

A disease that can be written as states and transitions is declared instead, with ss.Disease (see ss.SIR), which gives it every solver and describe(), equations(), and R0(). The v4 verbs that act on arrays work on both: ss.modify(hiv.rel_trans, ...), conditions such as hiv.cd4 < 200, and fitting the values in pars.

With strains=ss.Strains(...), each person carries one strain at a time (self.strain, the index of the strain of their current or last infection, -1 if none), which the disease’s code reads (e.g. in set_prognoses(), and strain_value() for a strain’s values). The strains are transmitted in one pass, each by those infectious with it at its rel_trans; each new case is infected by one of those who reached them in the step, at random, and takes their strain, unless protected against it (strain_sus(): protection from ss.immunity(due_to=<state>, rel_sus=matrix) by the strain they had, or the disease’s own), as a declared disease’s strains are passed on, by the same code (ss.solvers.Transmission).

Note: CRN safe.

Examples

class SIRS(ss.Infection):
    def __init__(self, **kwargs):
        super().__init__()
        self.define_pars(beta=ss.perday(0.05), init_prev=ss.bernoulli(0.01), dur_inf=10)
        self.define_states(ss.BoolState('recovered'), ss.TimeArr('ti_recovered'))
        self.update_pars(**kwargs)

    def step_state(self):
        done = (self.infected & self.ti_recovered.due()).uids
        self.infected[done] = False
        self.recovered[done] = True
        self.susceptible[done] = True # Protected only by the immunity of their strain, if any

    def set_prognoses(self, uids, sources=None):
        super().set_prognoses(uids, sources)
        self.infected[uids] = True
        self.recovered[uids] = False
        self.ti_infected[uids] = self.ti
        self.ti_recovered[uids] = self.ti + 1 + self.pars.dur_inf # Infected at the end of this step, so infectious from the next

# Two strains, the second more transmissible; recovering from one protects fully against it, and partly against the other
strains = ss.Strains(['H1', 'H3'], rel_trans=[1, 1.5], immunity=ss.immunity(due_to='recovered', rel_sus=[[1, 0.5], [0.5, 1]]))
sim = ss.Sim(diseases=SIRS(strains=strains, name='flu'), networks='random', n_agents=2000, unit='day', stop=100).run()
sim.diseases.flu.strain # The strain of each person's current or last infection

transmit
diseases.Infection.transmit()

Determine who gets infected on this timestep via transmission on the network

Computes the effective transmissibility and susceptibility, calls transmit_route() for each network (or other route), and keeps the first infection of each agent (ss.solvers.Transmission.first_infections()). InfectionLog

diseases.InfectionLog(disease=None, networks=None)

Record infections

The infection log records transmission events and optionally other data associated with each transmission. Entries are stored as one chunk of arrays per call, so logging is cheap; they are combined when the log is read. Basic functionality is to track transmission with

Disease.infection_log.add_entries(targets, sources, t)

or, for a single infection,

Disease.infection_log.append(source, target, t)

Seed infections can be recorded with a source of None (or NaN), although all infections should have a target and a time. Other data can be captured in the log, either at the time of creation, or later on. For example

Disease.infection_log.add_entries(targets, sources, t, variant=variants)

records extra data for each infection (ss.Infection records the network this way). Modules can optionally add per-infection outcomes later as well, for example

Disease.infection_log.add_data(uids, t_dead=2024.25)

This would be equivalent to having specified the data at the original time the log entry was created - however, it is more useful for tracking events that may or may not occur after the infection and could be modified by interventions (e.g., tracking diagnosis, treatment, notification etc.)

A table of outcomes can be returned using InfectionLog.to_df(), and a NetworkX graph with InfectionLog.to_graph().
