diseases

diseases

Diseases: the base class (ss.Disease), diseases with transmission written as code (ss.AgentDisease), the record of who infected whom (InfectionLog), and the textbook models (ss.SIR, ss.SIS, ss.SEIR)

ss.Disease exists so that one class can hold a disease declared from states and transitions, written as code, or both. A declared disease runs with any solver; ss.AgentDisease and other code that works on individual agents runs as agents.

Used with: agents and compartments; declared and coded modules

AgentDisease

diseases.AgentDisease(pars=None, strains=None, **kwargs)

A transmitted disease written as code, as agents: the plain array operations of an infection, each a method to override

Gives the susceptible, infected (and infectious, by default the same), rel_sus, rel_trans, and ti_infected states; seeds init_prev of the people at the start; and each step transmits from transmissibility() to susceptibility() over the sim’s networks (transmit()), counts the new cases in the infection result, and gives them their prognoses (set_prognoses()). A subclass overrides only what it needs: usually set_prognoses(), for what happens to those infected, and step_state(), for how their states change; those infected before birth (over ss.PrenatalNet) go to set_congenital() instead, which a disease with outcomes at birth overrides. Anything else is plain code on the arrays. The betas of the networks are route_betas(), which can be overridden too (e.g. by sex).

With strains=ss.Strains(...), each person carries one strain at a time (self.strain, the index of the strain of their current or last infection, -1 if none), which the disease’s code reads (e.g. in set_prognoses(), with strain_value() for a strain’s values). The strains are transmitted in one pass, each by those infectious with it at its rel_trans; each new case is infected by one of those who reached them in the step, at random, and takes their strain, unless protected against it (strain_sus(): protection from ss.immunity(due_to=<state>, protection=matrix) by the strain they had, or the disease’s own), as a declared disease’s strains are passed on.

An infection in a step happens at its end, so a course scheduled from it starts at the next step: schedule a move dur steps after it at self.ti + 1 + dur, in an ss.TimeArr, and take it when due(). The seeds are dated by the step before the first (self.ti is -1 while they are set), so they have the same course.

A disease that can be written as states and transitions is shorter declared (see ss.SIR), and runs with every solver.

Example

class SIR(ss.AgentDisease):
    def __init__(self, **kwargs):
        super().__init__()
        self.define_pars(beta=ss.perday(0.05), init_prev=0.01, dur_inf=10)
        self.define_states(ss.BoolState('recovered'), ss.TimeArr('ti_recovered'))
        self.update_pars(**kwargs)

    def step_state(self):
        done = (self.infected & self.ti_recovered.due()).uids
        self.infected[done] = False
        self.recovered[done] = True

    def set_prognoses(self, uids, sources=None):
        super().set_prognoses(uids, sources)
        self.ti_recovered[uids] = self.ti + 1 + self.pars.dur_inf

sim = ss.Sim(diseases=SIR(), networks='random', unit='day', stop=100).run()

# With two strains, the second more transmissible; recovering from one protects fully against it, and partly against the other
class SIRS(SIR):
    def step_state(self):
        super().step_state()
        self.susceptible[self.recovered] = True # Protected only by the immunity of their strain

    def set_prognoses(self, uids, sources=None):
        super().set_prognoses(uids, sources)
        self.recovered[uids] = False

strains = ss.Strains(['H1', 'H3'], rel_trans=[1, 1.5], immunity=ss.immunity(due_to='recovered', protection=[[1, 0.5], [0.5, 1]]))
sim = ss.Sim(diseases=SIRS(strains=strains, name='flu'), networks='random', unit='day', stop=100).run()
sim.diseases.flu.strain # The strain of each person's current or last infection

Disease

diseases.Disease(
    *args,
    pars=None,
    strains=None,
    stratify=None,
    solver=None,
    _names=None,
    **kwargs,
)

A disease: states people are in and the transitions between them (declared), code, or both

Declared from its states and transitions, no methods need to be defined, and the disease can be run with any solver (see ss.Sim):

S, I, R = ss.states(3)
sir = ss.Disease(
    infection = S >> I @ 0.3 * I,
    recovery  = ss.Transition(I, R, dur=10),
    init_prev = 0.01,
)

The same disease can be declared in a class body (the class form), which can also add behavior by defining methods; ss.SIR, ss.SIS, and ss.SEIR are written this way.

A disease can also be written as code: a subclass that declares nothing, defines its per-agent arrays (define_states()), and changes them in its own step_state() and step(); it runs as agents. One class can mix the two, e.g. a declared natural history and a coded array that its step() updates after super().step() has taken the declared transitions. Each lifecycle method runs the declared part through the disease’s engine (which, for a disease that declares nothing, has nothing to run), so an override calls super() as for any module. ss.AgentDisease adds transmission written as code: transmit(rel_trans=..., rel_sus=...), the same array operation as a declared transmission’s (see transmit()).

Note: CRN safe as agents.

A disease’s own solver= is useful when one disease of a sim needs a different way of running as agents from the others:

  • ss.solvers.abm(step='wholestep'): by steps, with rates applied over whole steps to those in the state at the start of the step, as code with ss.bernoulli() does; faster, and a little less exact when the step is coarse
  • ss.solvers.abm(step='events'): event by event, in continuous time
  • by default: the sim’s, if it names a step; else the class’s suggested_solver (e.g. suggested_solver = ss.solvers.abm(step='wholestep') in the class body); else 'midstep' (see ss.solvers.abm() and ss.solvers.agent_solver())

The results are the number in each state (I), the flow along each transition by its name (infection, with its cumulative total as res.infection.cum), and the results and outcomes declared (e.g. active=(E + I).frac). Its infected states also give the results infected, the number in them, and prevalence, their fraction of everyone in the disease’s states, unless it defines its own: those of its force of infection (E and I in S >> E @ beta*I), or those it says are infected (infected = E + I + H, ss.State(infected=True), or ss.states('S E I H R', infected='E I H')).

Examples

# Operator form: declare the states, then the transitions
S, I, R   = ss.states(3)
infection = S >> I @ 0.3 * I
recovery  = I >> R @ ss.days(10)
sir = ss.Disease(infection, recovery, init_prev=0.01)
ss.Sim(sir, stop=100).run().plot()

# Class form: for when there is behavior that is not a transition
class SIR(ss.Disease):
    S, I, R   = ss.states(3)
    infection = S >> I @ 0.3 * I
    recovery  = I >> R @ ss.days(10)

# Written as code: a disease that is not transmitted
class Anemia(ss.Disease):
    def __init__(self, **kwargs):
        super().__init__()
        self.define_pars(p_onset=ss.bernoulli(0.01))
        self.update_pars(**kwargs)
        self.define_states(ss.BoolState('anemic', label='Anemic'))

    def step_state(self):
        self.anemic[self.pars.p_onset.filter()] = True

R0
diseases.Disease.R0(matrix=False)

The basic reproduction number, from the next-generation matrix at the disease-free state

By definition it is in a population with no infection and no immunity: the people infected at the start are left out, and everyone else is taken to be in the first state (e.g. S), each group keeping its size, whoever starts immune (init=dict(R=0.9)). So where transmission is density-dependent (beta*I.n), R0 is for the population less the people seeded, which matters only when many are (half the people seeded halves it). If no transition links some states to the first (a chain of states for each host species), their people are in the state their own chain starts from. People filled by a constant inflow (births of a number a day) and counts that are not people (mosquitoes) are at their equilibrium, which the inflow and the rates out of them set (Λ/μ). The reproduction number at the start, with any immunity, is in the line a run prints as it starts, when it differs (R0 = 15.2 (R = 1.52 at the start, with 10% susceptible)).

The model is laid out as an ODE: if the disease is in a sim, a copy of that sim is made with solver='ode', with its mixing and stratification; otherwise a sim with the disease alone, under homogeneous mixing, with the default number of people. Values that vary in time (a seasonal β) are taken at the start, so this is R0 at the start time. A sim runs a copy of the disease it is given, so the R0 of a sim’s model is sim.diseases.<name>.R0(); this matters where a count is a number rather than a fraction of the people (mosquitoes per person).

This is the largest eigenvalue of the next-generation matrix. Where infection passes through a vector (people infect mosquitoes, which infect people), each passage is a generation, so R0 is the square root of the classical Ross–Macdonald value. Shedding into a reservoir that is a count (such as water) is not an infection, so there R0 is the number of people infected through the reservoir by one person.

Parameters
Name Type Description Default
matrix bool if True, return the next-generation matrix (over the infected compartments of every group) rather than its largest eigenvalue False
Example
S, I, R = ss.states(3)
sir = ss.Disease(infection=S >> I @ 0.3*I, recovery=ss.Transition(I, R, dur=10))
sir.R0() # 3.0
Rt
diseases.Disease.Rt()

The reproduction number over the course of a run, as a result: the number one infectious person infects at each time point

This is R0 at the state of the run at each time point: the largest eigenvalue of the next-generation matrix with the people in each state of each group as they were then (so fewer when some are immune), and the rates as they were then (so lower while an ss.modify() halves β). It falls below 1 as an outbreak peaks. As in R0(), the model is laid out as an ODE, a copy of the sim with solver='ode', stepped alongside the run; a run as agents is taken by the counts in each state of each group. A state with several compartments (the stages of a dwell time) is split among them as in the copy; and the copy is what an intervention triggered by the state of the run sees.

Example

sim.diseases.sir.Rt().plot() # From 3 at the start, below 1 after the peak

transmit
diseases.Disease.transmit(
    transition=None,
    rel_trans=None,
    rel_sus=None,
    beta=None,
)

Who is infected in this step by transmission: by one of the disease’s declared transmissions (transition), or, as agents, from the transmissibility and susceptibility of each agent (rel_trans and rel_sus), over the sim’s networks and other routes

Declared. A declared disease’s transmissions are its transitions whose rate depends on contact with infectious people (e.g. S >> I @ beta*I). Override this to write one as code, and call super().transmit(transition) for what the solver would do, e.g. to add a route of its own or remove some of the cases. The engine calls it once a step for each transmission, and moves those it gives along that transition, counted in its flow. A disease with one transmission can leave out the argument (def transmit(self):); with several, transition says which (e.g. if transition.name == 'infection':). As agents, it gives the new cases’ UIDs (those not in one of the transition’s source states are not moved); as compartments, the number infected in each group (or one number), taken from the source states in proportion. Under the ODE, it is taken once a step, at the start, as a move of that many (as ss.move() from code is), so the ODE no longer integrates that transition within the step: give a rate (e.g. S >> I @ (lambda self, sim: ...)) to keep it exact. Anything that needs individuals (UIDs) raises an error in a compartmental run; if isinstance(self.sim.solver, ss.solvers.ode): can give each its own.

As array operations. With rel_trans and rel_sus, it is the same transmission as an operation that code calls, as agents (in a disease written as code, or in a declared one’s own code): each edge of a network from u to v transmits with probability 1 − exp(−rel_trans[u]·rel_sus[v]·H), where H is the hazard of the network’s chance for the step (see ss.Network.transmit()), with the modifiers and products on rel_trans and rel_sus applied (so the disease says allow_modifiers = ('rel_sus', 'rel_trans')), and the draws of each edge from the disease’s trans_rng; other routes (e.g. a mixing pool) give their own (compute_transmission()). Someone reached by several is infected by the first, which is their source, recorded with the route in an ss.infection_log. Nobody is moved: the code that calls it says what happens to those infected.

InfectionLog

diseases.InfectionLog(disease=None, networks=None, timeline=None)

A record of who infected whom, and when: kept by a disease when an analyzer needs it (e.g. ss.infection_log), to trace chains of transmission

The infection log records transmission events and optionally other data associated with each transmission. Entries are stored as one chunk of arrays per call, so logging is cheap; they are combined when the log is read. Basic functionality is to track transmission with

Disease.infection_log.add_entries(targets, sources, t)

or, for a single infection,

Disease.infection_log.append(source, target, t)

Seed infections can be recorded with a source of None (or NaN), although all infections should have a target and a time. Other data can be captured in the log, either at the time of creation, or later on. For example

Disease.infection_log.add_entries(targets, sources, t, variant=variants)

records extra data for each infection (ss.Disease.transmit() records the network this way). Modules can optionally add per-infection outcomes later as well, for example

Disease.infection_log.add_data(uids, t_dead=2024.25)

This would be equivalent to having specified the data at the original time the log entry was created - however, it is more useful for tracking events that may or may not occur after the infection and could be modified by interventions (e.g., tracking diagnosis, treatment, notification etc.)

A table of outcomes can be returned using InfectionLog.to_df(), and a NetworkX graph with InfectionLog.to_graph(). An analyzer that follows transmission as the sim runs reads each step’s entries with to_df(ti=self.ti):

new = sim.diseases.sir.infection_log.to_df(ti=self.ti) # In an analyzer’s step()

An SIR model: susceptible, infected, and recovered, optionally with deaths from infection

Declared from states and transitions (see ss.Disease), so it runs with any solver: as agents over networks, or as compartments. It is the textbook SIR: the infectious period is exponential, as any declared duration is, and nobody dies of the infection unless p_death is given. Its defaults are those of a respiratory infection: infectious for 10 days, with an R0 of 3 without a network (β × the duration); with a network, β is per contact, so R0 is that many times the number of contacts.

Note: CRN safe as agents.

Parameters

Name Type Description Default
beta float/ss.per/dict the transmission rate (per contact, if there are networks, over each step of the contact, so ss.probperday(p) gives each contact a chance p in a day; a dict gives one per network, and default= for the networks it does not name)
init_prev float the fraction of people who start infected (for a number of people, give init_n= instead, e.g. init_n=10)
dur_inf float/ss.Duration/ss.Dist the mean time that people are infected for (by default 10 days), as an exponential; give a distribution (e.g. ss.lognormal(mean=ss.days(10))) for another shape
p_death float the probability of death from infection, at the end of the infection (by default 0)
kwargs dict passed to ss.Disease, e.g. name

An SIR model written as code, with a lognormal dur_inf and p_death=0.01, is ssl.AgentSIR.

Example

sim = ss.Sim(diseases=ss.SIR(beta=0.03, dur_inf=ss.days(10)), networks='random', n_agents=5000) # R0 of 3 with 10 contacts each
sim.run().plot()

An SIS model: people recover from infection and are susceptible again

Declared from states and transitions (see ss.Disease), so it runs with any solver. Its defaults are those of a respiratory infection that leaves no immunity: infectious for 10 days, with an R0 of 2 without a network, so that half of people are infected once it is endemic.

Note: CRN safe as agents.
