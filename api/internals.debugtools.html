internals.debugtools

internals.debugtools

Tools for debugging and profiling Starsim runs: sim.profile(), detailed diagnostics, and mock objects for testing a module without a sim

They exist so that a slow or surprising run can be looked into without changing the model.

Used with: agents and compartments; declared and coded modules

Classes

Name Description
Diagnostics Helper class for storing detailed diagnostic information; see sim.set_diagnostics() for usage; not to be used directly
Profile Class to profile the performance of a simulation

Diagnostics

internals.debugtools.Diagnostics(sim, rvs=True, states=True, detailed=False)

Helper class for storing detailed diagnostic information; see sim.set_diagnostics() for usage; not to be used directly

It exists to find where two runs that should match first differ.

Parameters

Name Type Description Default
sim ss.Sim the sim to attach diagnostics to required

states bool / str whether to track people states; if a string, used as the export filename (default ‘debug_states.json’) True
detailed bool if True, store full arrays; if False, store summary statistics only False

Profile

internals.debugtools.Profile(
    sim,
    follow=None,
    do_run=True,
    plot=True,
    verbose=True,
    **kwargs,
)

Class to profile the performance of a simulation

Typically invoked via sim.profile().

Parameters

Name Type Description Default
sim ss.Sim the sim to profile required
follow func / list a list of functions/methods to follow in detail None
do_run bool whether to immediately run the sim True
plot bool whether to plot time spent per module step True
**kwargs dict passed to sc.profile() {}

Examples

import starsim as ss
import starsim.library as ssl

net = ss.RandomNet()
hiv = ssl.HIV() # A disease written as code
sim = ss.Sim(networks=net, diseases=hiv)
prof = sim.profile(follow=[net.add_pairs, hiv.transmit])
prof.disp()

check_sims_match

internals.debugtools.check_sims_match(*args, full=False)

Shortcut to using diff_sims() to check if multiple sims match

Parameters

Name Type Description Default
args list a list of 2 or more sims to compare ()
full bool if True, return whether each sim matches the first False

Examples

s1 = ss.Sim(diseases='sir', networks='random').run()
s2 = ss.Sim(pars=dict(diseases='sir', networks='random')).run()
s3 = ss.Sim(diseases=ss.SIR(), networks=ss.RandomNet()).run()
assert ss.debugtools.check_sims_match(s1, s2, s3)

diff_sims

internals.debugtools.diff_sims(
    sim1,
    sim2,
    skip_key_diffs=False,
    skip=None,
    full=False,
    output=False,
    die=False,
)

Compute the difference of the summaries of two simulations, and print any values which differ.

Parameters

Name Type Description Default
sim1 Sim / MultiSim / dict either a simulation/MultiSim object or a dict of its summary (e.g. sim.summary.value.to_dict()) required
sim2 im / dict ditto required
skip_key_diffs bool whether to skip keys that don’t match between sims False
skip list a list of values to skip None
full bool whether to print out all values (not just those that differ) False
output bool whether to return the output as a string (otherwise print) False
die bool whether to raise an exception if the sims don’t match False

Examples

s1 = ss.Sim(rand_seed=1).run()
s2 = ss.Sim(rand_seed=2).run()
ss.debugtools.diff_sims(s1, s2)
