internals.modules

internals.modules

The base classes of the parts of a sim: ss.modules.Base and ss.Module, which diseases, networks, interventions, and the rest inherit from

They exist so that every part of a model has the same parameters, timeline, results, and place in the integration loop.

Used with: agents and compartments; declared and coded modules

Module

internals.modules.Module(name=None, label=None, pars=None, **kwargs)

The main base class for all Starsim modules: diseases, networks, interventions, etc.

A module declares its parameters (ss.par) and the arrays it keeps for each agent (ss.FloatArr, ss.BoolArr, …) in its class body, and its behavior in methods such as step(). Each parameter can then be given by keyword (or as pars=dict(...)), and the module’s code reads its value from self.pars; each array is an attribute of the same name. Each instance has its own copies.

A module whose parameters depend on its arguments can instead define them in its __init__(), with define_pars() and then update_pars(), which applies the arguments given (and raises for any it does not have); its arrays are defined with define_states().

Parameters

Name Type Description Default
name str a short, key-like name for the module (e.g. “randomnet”); if not given, the variable it is assigned to (net = ss.RandomNet() is “net”), else its default_name (see ss.Sim._name_modules()) None
label str the full, human-readable name for the module (e.g. “Random network”) None
pars dict values of the parameters declared in its class body, as an alternative to giving them by keyword None
kwargs dict values of those parameters, by name; or passed to ss.Timeline() (e.g. start, stop, dt)

Examples

class Decay(ss.Intervention):
    half_life = ss.par(ss.years(2)) # A parameter, given as Decay(half_life=ss.years(5))
    level = ss.FloatArr(default=1.0) # A value for each agent

    def step(self):
        self.level[:] *= 0.5**(self.t.dt/self.pars.half_life)

# The same, with the parameters defined in __init__()
class Decay(ss.Intervention):
    def __init__(self, **kwargs):
        super().__init__()
        self.define_pars(half_life=ss.years(2))
        self.update_pars(**kwargs)
        self.define_states(ss.FloatArr('level', default=1.0))

current_value
internals.modules.Module.current_value(key, uids=None)

A parameter (key is its name) with the modifiers active on it (ss.modify('tx.pars.p_treat', ...)), in its own type: one value, or one for each agent if they differ between agents

A module written as code reads a parameter from self.pars with the modifiers applied, which is one value. To apply a modifier that differs between people (e.g. with who=), its code reads the parameter with current_value(), and says so in its class, allow_modifiers = ('p_treat',).

Parameters
Name Type Description Default
key str the name of the parameter required
uids uids the agents to give the values of (default: one value, or an array of every agent, by UID, if they differ between agents) None
Example
class Treat(ss.Intervention):
    allow_modifiers = ('p_treat',) # ss.modify('treat.pars.p_treat', multiply=0.5, who=...) applies to those people only
    def step(self):
        uids = self.sim.diseases.sis.infected.uids
        treated = uids[np.random.rand(len(uids)) < self.current_value('p_treat', uids)] # ...
define_aliases
internals.modules.Module.define_aliases(overwrite=False, **kwargs)

Define aliases for states, e.g. self.define_aliases(infectious='infected')

An alias is used only if the attribute isn’t otherwise defined, so a subclass overrides it by defining a state of the same name (e.g. ss.AgentDisease treats everyone infected as infectious this way).

Each alias is the name of another state, or a callable taking the module, which is recomputed on each access (read only) and also generates a result of its name, as an ss.BoolState does (a string alias doesn’t, since its state is counted already). A lambda can’t be saved with plain pickle (sc.save() and ss.MultiSim use dill, so are fine).

Parameters
Name Type Description Default
overwrite bool if True, replace any existing state or alias of the same name, rather than raising False
kwargs dict mapping of alias name to either the name of a state, or a callable
Examples
self.define_aliases(infectious='infected') # Everyone infected is infectious
self.define_aliases(infected=lambda self: self.exposed | self.infectious) # Both E and I are infected
self.define_states(ss.BoolState('exposed'), infectious='infected') # Aliases can also be defined alongside states
define_class_parts
internals.modules.Module.define_class_parts(pars, arrs, given=None)

Define the parameters, arrays, and distributions declared in the class body (see class_parts()), each instance with its own copy, and apply the values given

Each parameter is also an attribute (mod.half_life), the instance’s own ss.par, which holds its value, as for a declared disease; setting it (mod.half_life = 3) sets the parameter. The module’s code reads the value from self.pars.

arrs dict the arrays (ss.Arr) and distributions (ss.Dist), by name required
given dict the values given for the parameters, by name None

from_func
internals.modules.Module.from_func(func)

Create a module from a function

The function takes the sim as its only argument, and becomes the module’s step(), so it is called on every timestep and does its own time gating (e.g. if sim.now == 2015:); the module is named after the function. A function given to interventions=, analyzers=, or to the sim is converted this way automatically.

Keyword arguments of the function with defaults are the module’s parameters, passed to it at each call; one given as ss.par with bounds can be fitted (sim.fit()), sampled (sim.sensitivity()), and set by name (ss.Sim(pars=...)) as any other, e.g. to fit a value set in code (see the last example). Such a module has no states or results of its own: for those, write a subclass.

Parameters
Name Type Description Default
func callable a function taking the sim, and optionally keyword arguments with defaults (its parameters) required
Returns
Name Type Description
mod Module an instance of cls whose step() calls func(sim)
Example
import starsim as ss

def knockdown(sim): # Halve transmission for one year starting in 2015
    if sim.now == 2015:
        sim.diseases.sis.rel_trans[:] *= 0.5

# Explicit construction ...
intv = ss.Intervention.from_func(knockdown)
sim = ss.Sim(diseases='sis', networks='random', interventions=intv)

# ... or equivalently, let the sim convert it automatically:
sim = ss.Sim(diseases='sis', networks='random', interventions=knockdown)

# A value set in code, fitted: the fraction of transmission left in 2015
def knockdown(sim, frac=ss.par(0.5, bounds=[0.1, 1])):
    if sim.now == 2015:
        sim.diseases.sis.rel_trans[:] *= frac

record_events
internals.modules.Module.record_events()

Record the results about what happened in the step (flows), at its index: e.g. self.results.doses[self.ti] = self.n_doses

Called at the end of every step, after every module’s step and the deaths (see ss.loop.Loop). The state then is that of the next time point, so a result that also needs a stock reads it from its result, recorded at the start of the step (e.g. self.sim.results.alive[self.ti]), or is worked out over the whole run in finalize_results().

record_states
internals.modules.Module.record_states(names=None)

Record the results that are the state at the start of the step (stocks), at its index; by default, the count of each state

Called at the start of every step, before any module’s step (see ss.loop.Loop), so the results at a time point are the state there: e.g. self.results.n_on_art[self.ti] = self.on_art.sum(). A result about what happens in the step (a flow, or one that needs a flow) goes in record_events() instead.

Parameters
Name Type Description Default
names list the states to count (default: every ss.BoolState, and derived state) None
