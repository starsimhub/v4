utils

utils

Numerical utilities and other helper functions

What is shared by the rest of the code, and doesn’t belong to any one part of it: named dictionaries of modules (ndict), warnings, cleaning input data, plotting arguments, and returning figures and tables.

Used with: agents and compartments; declared and coded modules

method_wrapper

utils.method_wrapper(func)

A method that Starsim wraps in a subclass (e.g. init(), see outermost); a subclass defines __call__(self, obj, *args, **kwargs), which calls self.func

It is a class rather than a closure so that a class defined in a script, which dill pickles by value (e.g. to send a sim to ss.parallel()‘s workers), pickles with its own method and not with the globals of the module that wrapped it: dill copies those, and with them, by value, any module not installed in site-packages (e.g. Sciris or Starsim installed as editable), which may not pickle at all (“cannot pickle’_thread._local’ object”).

ndict

utils.ndict(*args, type=None, **kwargs)

A dictionary of named items, such as a sim’s modules (sim.diseases), which can also be called for its values (sim.diseases())

Each item is added under its name (or the key given), and a key can be added only once, so that two modules can’t silently take the same name.

skipkey

utils.skipkey()

The name of a key for sc.search() to skip, which is equal only to a string of that name

sc.search() compares each key it meets with the keys to skip, so a plain name would be compared with every key of every dict in a module, including dates (e.g. an analyzer’s results by date), and a date compared with a string that is not a date raises (see ss.date). Use skipkeys(names) for a list of them.

assigned_name

utils.assigned_name(obj)

The name of the variable an object being made is assigned to, e.g. “campaign” in campaign = ss.vaccinate(...), read from the code that made it (the frame above its constructors) as the instruction after the call; None if the result is not stored straight in a variable (e.g. it is returned, put in a list, or passed on). It is read when the object is made, so the name is that of its first variable, whatever variable holds it later (e.g. in a loop)

caller_names

utils.caller_names(depth=1, skip=None)

The names of the variables in the code that called the caller (depth levels above it), as a dict of the name of each object by its id: its local variables, else its global ones, and only for an object bound to exactly one of them. A declared disease (ss.Disease(infection, recovery)) and a sim (ss.Sim(diseases=sir), sim.new(interventions=campaign)) look up the names of what they are given once, here; nothing else does. If the stack is not that deep (e.g. from R via reticulate), the names given by named(), if any. The code of the function skip, if that is the code above, does not count.

fn_args

utils.fn_args(func, names=fn_names, positions=None)

The arguments a user function takes, in its order: those it names among names (by default self, the module whose function it is; sim; and uids, the agents it is for), so any of fn(sim), fn(self, sim), fn(sim, uids), fn(self, sim, uids) (or none) can be written; a function whose arguments have other names takes them by position (fn(s) is the sim, fn(s, u) the sim and the agents, fn(m, s, u) all three). Arguments with defaults (fn(sim, years=5)) are not counted. Worked out once for each function.

plot_args

utils.plot_args(kwargs=None, _debug=False, **defaults)

Split the keywords given to sim.plot() and other plotting functions among the parts of the plot they are for (the figure, the lines, the data, and so on)

Note: the kwargs supplied to the parent function should be supplied as the first argument of this function; keyword arguments to this function are treated as default values that will be overwritten by user-supplied values in kwargs. The argument “_debug” is used internally to print debugging output, but is not typically set by the user.

Parameters

Name Type Description Default

plot_kw dict passed to plt.plot()

style_kw dict passed to sc.options.with_style(), for controlling the detailed plotting style

Returns

Name Type Description
A dict-of-dicts with plotting arguments, for use with subsequent plotting commands

Valid kwarg arguments are:

- fig: 'figsize', 'nrows', 'ncols', 'ratio', 'num', 'dpi', 'facecolor'
- plot: 'alpha', 'c', 'color', 'lw', 'linewidth', 'ls', 'linestyle', 'marker', 'markersize', 'ms'

shrink

utils.shrink(obj=None, attrs=None, verbose=False)

Replace one or more object attributes in-place with an ss.utils.Shrunk() placeholder.

Used to save memory or remove circular references, especially when running large numbers of sims. It is good practice to write shrink() methods for modules to remove any temporary arrays or other memory-intensive objects.

ss.utils.shrink() can be used to either manually replace an object, or replace multiple attributes of an object in-place. It is used rather than simply deleting attributes or setting them to None to make it clear that the attributes were intentionally removed.

Parameters

Name Type Description Default
obj object the object to shrink in-place (optional) None
attrs str / list the attributes of the object to shrink None
verbose bool if True, print warnings about missing attributes False

Examples

# "Shrink" (remove) the People object
sim = ss.Sim()
ss.utils.shrink(sim, 'people')

# Equivalent behavior, used manually
sim.people = ss.utils.shrink()

standardize_data

utils.standardize_data(
    data=None,
    metadata=None,
    min_year=1800,
    out_of_range=0,
    default_age=0,
    default_year=2024,
)

Standardize formats of input data

Input data can arrive in many different forms. This function accepts a variety of data structures, and converts them into a Pandas Series containing one variable, based on specified metadata, or an ss.Dist if the data is already an ss.Dist object.

The metadata is a dictionary that defines columns of the dataframe or keys of the dictionary to use as indices in the output Series. It should contain:

  • metadata['data_cols']['value'] specifying the name of the column/key to draw values from
  • metadata['data_cols']['year'] optionally specifying the column containing year values; otherwise the default year will be used
  • metadata['data_cols']['age'] optionally specifying the column containing age values; otherwise the default age will be used
  • metadata['data_cols'][<arbitrary>] optionally specifying any other columns to use as indices. These will form part of the multi-index for the standardized Series output.

If a configured column is not present in the data, a known synonym is used instead if one is available (see ss.utils.col_synonyms); for example, year data labeled “Time” (as in UN World Population Prospects data) is used for a data column configured as “Year”. Explicitly configured column names always take precedence over synonyms.

If a sex column is part of the index, the metadata can also optionally specify a string mapping to convert the sex labels in the input data into the ‘m’/‘f’ labels used by Starsim. In that case, the metadata can contain an additional key like metadata['sex_keys'] = {'Female':'f','Male':'m'} which in this case would map the strings ‘Female’ and ‘Male’ in the original data into ‘m’/‘f’ for Starsim.

Parameters

Name Type Description Default
data (pandas.DataFrame, pandas.Series, dict, int, float) An associative array or a number, with the input data to be standardized. None
metadata dict Dictionary specifying index columns, the value column, and optionally mapping for sex labels None
min_year float Optionally specify a minimum year allowed in the data. Default is 1800. 1800
out_of_range float Value to use for negative ages - typically 0 is a reasonable choice but other values (e.g., np.inf or np.nan) may be useful depending on the calculation. This will automatically be added to the dataframe with an age of -np.inf 0
default_age float the age to use if the data has no age column 0
default_year float the year to use if the data has no year column 2024

Returns:

- A `pd.Series` for all supported formats of `data` *except* an `ss.Dist`. This series will contain index columns for 'year'
  and 'age' (in that order) and then subsequent index columns for any other variables specified in the metadata, in the order
  they appeared in the metadata (except for year and age appearing first).
- An `ss.Dist` instance - if the `data` input is an `ss.Dist`, that same object will be returned by this function
