utils

utils

Numerical utilities and other helper functions

What is shared by the rest of the code, and doesn’t belong to any one part of it: named dictionaries of modules (ndict), warnings, cleaning input data, plotting arguments, and returning figures and tables.

Used with: agents and compartments; declared and coded modules

Classes

Name Description
ndict A dictionary of named items, such as a sim’s modules (sim.diseases), which can also be called for its values (sim.diseases())

ndict

utils.ndict(*args, type=None, kind=None, **kwargs)

A dictionary of named items, such as a sim’s modules (sim.diseases), which can also be called for its values (sim.diseases())

Each item is added under its name (or the key given), and a key can be added only once, so that two modules can’t silently take the same name.

A module can also be found by its default name (see ss.Module.default_name), if no other module here has the same one: sim.diseases.sir (or sim.diseases['sir'], or .get('sir')) is the only ss.SIR, even if it is called measles. This is only a way to find it: it is stored, listed, and iterated under its name. A name that is neither raises an error that lists the names there are, and where each came from (see ss.Module.name_origin()).

Parameters

Name Type Description Default
type type the type each item must be (a module of any type is also accepted) None
kind str what the items are, for messages, e.g. “diseases” (default “items”) None
args list the items to add, each a named item, or a list or dict of them
kwargs dict more items to add, by key

Examples

networks = ndict(ss.SexualNet(), ss.PrenatalNet())
networks = ndict([ss.SexualNet(), ss.PrenatalNet()])
networks = ndict({'sexual':ss.SexualNet(), 'prenatal':ss.PrenatalNet()})

count_by

utils.count_by(codes, n_codes, groups=None, n_groups=1, weights=None)

The number of agents with each code in each group (or the sum of their weights), in one pass over the agents, threaded for a large population

For a module written as code that keeps each agent’s state as a small whole number (e.g. 0 to 3 for S, E, I, R), to count them by state and place. The result doesn’t depend on the number of threads.

Parameters

Name Type Description Default
codes array each agent’s code, by UID (e.g. self.state.raw); those outside 0 to n_codes - 1 (e.g. of agents who have died, if given a code of their own) are not counted required
n_codes int the number of codes required
groups array each agent’s group, by UID, e.g. sim.groups.level('patch') (default: one group) None
n_groups int the number of groups 1
weights array each agent’s weight, by UID, to sum rather than count them None

Returns

Name Type Description
An array with a row for each code and a column for each group: whole numbers (int64), or the sums of the weights (float64)

Examples

counts = ss.utils.count_by(self.state.raw, 4, sim.groups.level('patch'), n_patches) # counts[2] is the number in I in each patch

plot_args

utils.plot_args(kwargs=None, **defaults)

Split the keywords given to sim.plot() and other plotting functions among the parts of the plot they are for (the figure, the lines, the data, and so on)

The kwargs given to the calling function are the first argument; keyword arguments to this function are defaults, overridden by kwargs. Each part takes the keywords listed in ss.utils.plotting_kw (e.g. figsize for the figure), or a dict of them, e.g. fig_kw=dict(...):

- fig: passed to `sc.getrowscols()`, then `plt.subplots()` and `plt.figure()`
- plot: passed to `plt.plot()`
- data: passed to `plt.scatter()`, for plotting the data (`data_alpha`, `data_color`, `data_size`)
- fill: for shaded areas (`fill_alpha`, `fill_color`, `fill_hatch`, `fill_lw`)
- legend: passed to `plt.legend()`
- style: passed to `sc.options.with_style()`
- return_fig: 'do_show', 'is_jupyter', 'filename' (see `ss.return_fig()`)

Parameters

Name Type Description Default
kwargs dict the keywords to split None
defaults dict the default values

Returns

Name Type Description
A dict-of-dicts with plotting arguments, for use with subsequent plotting commands

Examples

kw = ss.plot_args(kwargs, fig_kw=dict(figsize=(10,10))) # Explicit way to set figure size, passed to `plt.figure()` eventually
kw = ss.plot_args(kwargs, figsize=(10,10)) # Shortcut since known keyword

return_fig

utils.return_fig(fig, given=False, do_show=None, is_jupyter=None, filename=None)

Do postprocessing on the figure: save it, show it, and return it; not for the user, but its arguments can be given to any plot of results

Parameters

Name Type Description Default
fig Figure the figure required
given bool whether the figure (or axes) was given by the caller, who then shows it, so it is not shown unless do_show=True False
do_show bool whether to show the figure (by default, ss.options.show, and in Jupyter, always) None
is_jupyter bool whether in Jupyter (by default, ss.options.is_jupyter), where a figure that is shown is not also returned, so it is not displayed twice None
filename str if given, save the figure to this file (with sc.savefig()) None

Returns the figure, unless it is shown in Jupyter; so in Jupyter, fig = sim.plot(do_show=False) gives the figure, without showing it.
