Not for the user: the agent engine: a declared model run as agents (abm)

It also holds the transmission that diseases written as code use, so that both give the same numbers.

Agents

solvers.agents.Agents(module, sim, solver=None)

Runs a graph as agents

It exists so that a declared model can run with individuals, for what compartments cannot hold.

Each state that holds people is a boolean array over agents. A dwell time is sampled when an agent enters a state and the exit is scheduled; rates that depend on the state of the model are drawn each step, with competing rates out of one state resolved in a single draw; and contact-mediated transitions are drawn over the sim’s networks. States that are not people stay plain counts.

Transmission

solvers.agents.Transmission(module, sim)

Transmission as agents, the same for a declared disease (Agents, for its transmissions) and one written as code (ss.Infection.transmit_route(), through its engine, ss.solvers.Undeclared): who can transmit and be infected, with the modifiers and products on rel_trans and rel_sus applied (current_value()); who is infected over a network (over_network()); and who infected whom (first_infections())

Where the two differ, the caller says how:

  • Hazard or probability. over_network() takes the chance of an edge in the step. A declared disease gives 1 − exp(−β·dt) from its rate, or, on a network with acts, works out a hazard per act (Agents.transmit_acts()); one written as code gives its beta as the probability in the step, converting a rate the same way (ss.Rate.to_prob()).
  • Order and attribution. The routes are taken in the order of sim.networks, and on each, p1 to p2 and then p2 to p1; someone reached by several is infected by the first (first_infections()), which is the source in the infection log. With strains, every strain is passed on in one pass, and someone reached by several is infected by one of them drawn at random, whose strain they take (pick_sources()), and then only if they are not protected against it (unprotected()): declared or written as code, by the same code.
  • Random numbers. Each edge’s is drawn by its source and target from the disease’s trans_rng, so the same disease, by the same name, gives the same edges the same numbers, declared or written as code; and so are the draws of who infects whom, and of protection, which are keyed by the step alone (step_draw()).

Each agent infected, once, with who infected them and over which route: the first of pairs to reach them. Each pair is the sources, the targets, and the index of the route (one, or one for each), and any more values (e.g. a strain); returns the targets (sorted), and for each, the source (ss.dtypes.int_nan where not known), the route, and the more values, of the first pair to reach them

over_network
solvers.agents.Transmission.over_network(
    i,
    route,
    rel_trans,
    rel_sus,
    betas,
    name,
)

Who is infected over a network in the step: an edge from u to v transmits with probability rel_trans[u]·rel_sus[v]·net_beta(beta), times the modifiers on the route for v (see ss.Network.transmit()). On a network with acts, these all scale the hazard of each act, as for a declared disease (see transmit_acts()), not the chance over all the acts, so net_beta() is given the chance per act they leave

Parameters
Name Type Description Default
i int the index of the route in sim.networks, recorded for who infected whom required
route ss.Network the network required
rel_trans array the effective transmissibility of each agent, by UID (0 if not infectious) required
rel_sus array the effective susceptibility of each agent, by UID (0 if not susceptible) required
betas list the probability of transmission over an edge in the step, p1 to p2 and p2 to p1: each a number (0 for none, so no random numbers are drawn), a rate (ss.Rate.to_prob()), or an array of one for each of the network’s directions by sides (see ss.peract) required
name str what the modifiers on the route are under (see route_mult()) required
Returns
Name Type Description
A list of (sources, targets, i), for each direction that transmits
pick_sources
solvers.agents.Transmission.pick_sources(pairs, name)

With strains, each agent reached in the step, once, with who infected them and the rest of that pair’s values: one of those who reached them, each as likely (the first to happen is as likely to be any of them), drawn from pick_<name>. Each pair is the sources, the targets, the index of the route (one, or one for each), and any more values (e.g. a strain), as for first_infections()

route_mult
solvers.agents.Transmission.route_mult(name, route)

The multiplier on a transmission over a route, as a function of the edges and of the people who would be infected (see ss.connectors.route_mult()); name is that of a declared disease’s transmission, or rel_sus for a disease written as code

Uniforms for some agents from one of the transmission’s distributions (self.dists[key]), keyed by the step alone, so the same agents get the same numbers, declared or written as code; without common random numbers, its next draws

unprotected
solvers.agents.Transmission.unprotected(name, uids, kept)

Which of some agents reached by a strain are infected by it: each with the chance kept, the share of the force of infection of the strain that reaches them (1 − their protection against it), drawn from protect_<name>
