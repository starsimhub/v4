internals.conditions

internals.conditions

Conditions: who something applies to

A condition is written against the attributes of the people and modules in the sim, e.g. (ppl.age > 65) & ~sir.vaccinated. Written before the sim exists, it is lazy: an expression that is evaluated each time it is needed during a run, on agents in an agent-based run and on groups in a compartmental one. A function of the sim does the same job, for anything the operators cannot say.

Used with: agents and compartments; declared and coded modules

Classes

Cond

internals.conditions.Cond(op, *args)

A lazy condition: an unevaluated expression over the arrays of the people and modules in a sim

Conditions are not usually created directly: they are what comparisons and logical operators give when used on arrays that have not been initialized yet, on declared states, and on stratifications.

Parameters

Name Type Description Default
op str the operation: a leaf (‘people’, ‘state’, ‘dim’, ‘kind’, ‘array’, ‘incidence’, ‘event’, ‘memory’, ‘move’), an operator, ‘~’, or ‘isin’ required
args list the operands

Examples

ppl = ss.People(n_agents=10_000)
S, I, R = ss.states(3)
sir = ss.Disease(infection=S >> I @ 0.3*I, recovery=ss.Transition(I, R, dur=10))
eligible = (ppl.age > 65) & sir.S

exit For a set of states (A \| B): the event of leaving it for a state outside it

n The number of people the condition holds for: in a rate, for a set of states ((hiv.L \| hiv.A).n, the same as (hiv.L + hiv.A).n);
n_times For an event: how many times it has happened to each person, e.g. screening.n_times >= 2
since For an event: the time since it last happened to each person (infinite if never), e.g. cytology.since >= ss.years(5)
time_in For a set of states (A \| B): the time since entering it from outside it, in the sim’s unit (moves within the set do not reset it; NaN outside it)
total For a set of states ((E \| I).total, the same as (E + I).total), the number in them in the whole population

values In a running sim, as agents: the condition’s value for each agent alive, in the order of sim.people.auids (as ss.Arr.values)

Event

internals.conditions.Event(kind, obj, dst=None)

Something that happens to people at a moment: going through a transition (tr), one branch of it (tr.to(B)), or entering or leaving a state or a set of states (X.enter, (A | B).exit), where entering a set means arriving from outside it

An event is a condition, true for the agents it happened to from the moment they moved until the same point in the next step; it can be given to when= or ss.on(); it remembers, per person, whether (.ever), how often (.n_times), and how long ago (.since) it happened (agents only); and in a running sim, .uids are those agents.

Parameters

Name Type Description Default
kind str ‘tr’, ‘to’, ‘enter’, or ‘exit’ required
obj Transition / list the transition; or the states, as ss.States or (module, name) pairs required
dst State for ‘to’, the destination None

ref

internals.conditions.ref(path)

A reference to a state or transition of a module by its path, resolved when the sim is initialized: for a module made before the others exist

It stands for whatever is at the path: a state is a condition (the people in it), with .enter and .exit its events, as for a declared state; a transition ('ng.cure') is its event, the people who went through it. A path as a string, wherever a keyword takes a condition or an event (who='sir.I', when='sir.infection'), is the same as ss.ref() of it.

Parameters

Name Type Description Default
path str the module and the state or transition, e.g. 'hpv18.X' required

Examples

canceled = (S + P + C + L) >> Z @ ss.on(ss.ref('hpv18.X') | ss.ref('hpv31.X'))
seek = ss.treat(drug, when=ss.ref('ng.C').enter) # For a module made from a string
test = ss.screen(dx, when=ss.ref('ng.infection')) # The same as when='ng.infection'
