solvers.choose

solvers.choose

Not for the user: choosing the solver: which engine runs a declared model, and why (choose_solver()), and the steps that build a declared model before it is run (parameters by name, births and deaths of the population, a named population, the unit, life tables)

It exists so that a model need not say how it runs: the choice is made from what it holds, and the reason is kept. Modules written as code are taken into account, and get an engine too.

Used with: agents and compartments; declared and coded modules

Undeclared

solvers.choose.Undeclared(module, sim)

The engine of a disease that declares no states or transitions (see ss.Disease): there is nothing for it to run, so the disease’s own code is all of it. It gives that code what a declared disease’s engine gives its own, as agents: the modifiers and products on its rel_sus, rel_trans, and parameters (dis.current_value(), and self.pars while it runs), transmission over the networks (ss.Infection.transmit_route(); see Transmission), and, for a delivery, the people its conditions select and a cure (force())

It exists so that code written for a disease can act on any disease in the same way.

auto_reasons

solvers.choose.auto_reasons(sim)

The reasons, from the capability record, that solver='auto' runs the model as agents (none if it runs it as compartments)

choose_engine

solvers.choose.choose_engine(sim)

Whether JAX takes the sim’s whole run of the ODE, as ss.gradients runs it, rather than the kernels, and why

By sim.jax: True for JAX, False for the kernels, or None (the default) to choose: JAX if the run would take the kernels more than jax_after seconds (see kernel_seconds()). Once started, JAX takes 0.1 to 0.3 times as long as the kernels for the ODE over many groups, but starting it takes about half a second in a session (0.3 s to import it, and 0.1 to 0.25 s to trace a model; compiled code is kept on disk), which a short run would notice. The choice depends on the model only (kernel_seconds() is worked out from its size, never timed), not on what has run before, whether the kernels are compiled, or the load on the machine (and an ODE run in JAX agrees with the kernels to about 1e-14). The other solvers are run by the kernels, as is a model JAX does not cover (see why_not()), with a note if JAX was asked for.

Returns whether to use JAX, and the reason, also kept as sim.engine_reason.

choose_solver

solvers.choose.choose_solver(sim)

Work out the sim’s unit and solver; see ss.Disease for declaring a model that can be run with different solvers

Agents are made only when something needs them, whether the model is declared or written as code: a sim of modules written as code with nothing per person (e.g. an ODE of its own in NumPy) has no agents, and one with per-person arrays (Starsim 3’s diseases written as code) runs as agents. Which engine then takes a whole stochastic compartmental run, JAX or the kernels, is chosen when the sim is run, by choose_engine().

The steps: the modules are gathered and the declared model is built (init_model()); what matters to the choice is recorded (init_capabilities()), with what the layout of the compartments refuses, found by making it (init_layouts()); the solver is chosen; and the population is made ready for it (init_agents() or init_compartments()), and checked. The layouts are made once: a compartmental run uses them, unless its groups changed since.

init_capabilities

solvers.choose.init_capabilities(sim)

One record for each ingredient that changes which solvers can run the model, read by solver='auto', sim.describe(), and the CapabilityError of a compartmental solver that was asked for

Each record has the ingredient; the reason it makes auto run the model as agents (reason); whether it stops a compartmental solver that was asked for (fatal); and whether auto runs as agents for it (switch): see capabilities. Code is never run to find out: setting compartmental = True or False on a module (or its class) says whether it works on groups, and agent_reasons() is what a module says for itself. Any module written as code that says nothing, and the code and functions of a declared module, run beside the compartments (and raise a CapabilityError if they ask for agents). What the layout of the compartments refuses is not predicted here: init_layouts() makes the layout, which runs none of the model’s code, and adds its refusal as a record.

init_crossings

solvers.choose.init_crossings(sim, layouts=None)

In a compartmental run: track jointly the states of diseases that refer to each other, or whose people are born or die (see crossing_groups())

For example, ss.modify(hiv.rel_trans, multiply=3, where=syph.I) needs the number of people with HIV who also have syphilis. Each disease in a crossing becomes a dimension of the sim, whose levels are its compartments and which applies to the people of the others, so the model grows to the product of their compartments, which is counted before anything is made, and kept within ss.options.max_joint. See ss.solvers.Crossing.

kernel_seconds

solvers.choose.kernel_seconds(sim)

About how long the compiled kernels would take for a whole run of the ODE, from the size of its model alone: its time points, substeps, groups, compartments, flows, movers, the mixing between groups and places, and the stages of the integrator (see ss.kernels.compiled_seconds(): 0.93 to 1.6 times the time taken, for runs of more than 0.05 s). It never times anything, so the estimate (and the engine choose_engine() picks) is the same for a model whatever has run before, whether the kernels are compiled, and whatever else the machine is doing. It counts the substeps that the rates at the start need, not those an ODE adds as an epidemic grows, and leaves out values that vary in time, so it errs toward the kernels, which start at once.

solver_table

solvers.choose.solver_table()

What decides which engine runs a model, as a dataframe: a row for each rule, in the order they are read, with a column for each engine: agents, compartments (one step at a time), kernels (the whole run in one call), and jax (the ODE in JAX). In compartments, “if asked” is what solver='auto' runs as agents, but a compartmental solver that was asked for runs, approximating it.

Example:

ss.solvers.solver_table()
