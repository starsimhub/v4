connectors

connectors

Connectors, which link modules as the sim runs: e.g. one disease making another more likely

Most links between diseases need no connector, since diseases can read each other’s states (e.g. in a rate). A connector is for the rest, e.g. seasonal forcing or the effect of a coinfection. The one most used is ss.modify(), which changes a named quantity while a condition holds, e.g. a seasonal ss.modify(sir.rel_trans, multiply=ss.seasonal(amplitude=0.2, peak='January')).

Used with: agents and compartments; declared and coded modules

modify

connectors.modify(
    target,
    multiply=None,
    add=None,
    set=None,
    efficacy=None,
    frac=None,
    network=None,
    who=None,
    when=None,
    until=None,
    start=None,
    stop=None,
    name=None,
    **kwargs,
)

Change a named quantity while a condition holds: scale it, shift it, or set it

A modifier never overwrites the quantity it changes: the base value is kept, and the value used is (set value if any, else base) × multipliers + addends over the modifiers that are currently active. It can be passed to a sim in connectors (interactions that are part of the model) or interventions (policy), or be a member of a declared disease, as part of its natural history.

The target can be any of these (for a modifier that is a member of a disease, its own, e.g. beta, recovery, or 'rel_trans'):

  • a parameter, e.g. sir.pars.beta, including a parameter of any module written as code
  • a transition, e.g. sir.recovery, which scales its rate (or its probability, if it is a branch with p=)
  • sir.rel_sus or sir.rel_trans, each person’s susceptibility or infectiousness
  • the contacts of a network, as the network itself (e.g. ss.contacts('Kenya', layer='school'), matched by its name) or as a path ('school.pars.n_contacts')
  • the path of any of these as a string, e.g. 'sir.pars.beta'

For a transition with several destinations (e.g. ss.Transition(Tx, {R: 0.8, I: None}, rate=...)), the transition scales its rate (or its dwell time), and a destination ('tb.treatment.R') scales the probability of that destination. With an outcome for each strain carried (per_strain='each', with the probability of the first destination), that is the probability for the whole set of strains a person carries (e.g. that all are cured: Π c_k), not each strain’s.

Note: CRN safe.

Parameters

Name Type Description Default
target par / str the quantity to change (see above) required
multiply float multiply the quantity by this; like add and set, it can also be ss.by(...), a function of the sim, or an ss.timeseries, for changes at given times None
add float add this to the quantity: a parameter, or an inflow (a transition from ss.outside, e.g. CFUs shed into a reservoir), to which it adds an amount per unit time from outside the model None
set float replace the quantity with this (a parameter only) None
efficacy float for protection such as a condom or a needle program, the fraction of the risk it removes: the same as multiply=1 - efficacy (give one of them) None
frac float with multiply= or efficacy=, the fraction of acts (or, on a route without acts, of contacts) it acts on: the hazard is multiplied by 1 − frac·(1 − multiply), exactly, since hazards add; a number, an ss.timeseries, an ss.by, or (with network=, as agents) a function of the network returning one value per edge (e.g. lambda net: net.edges.condoms) None
network str / list for a modifier of a transmission, the network or networks (by name, as in the sim’s networks=, including mixing pools) it applies on; by default, every one. On a parameter (e.g. tb.pars.beta), it acts on every transmission the parameter scales (e.g. an infection and its reinfections). A disease written as code has no transmission to name, so on a network the target is its rel_sus (of the people who would be infected over it) None
who Cond / str / func who it applies to: a condition (e.g. sir.vaccinated, or a state by its path, who='sir.I', as ss.ref('sir.I')), a condition on a count (e.g. sir.I.n > 1000, worked out at each step; in compartments, as part of the rates where it can be, so the run stays in the kernels), or a function of the sim (default: everyone); with network=, the people who would be infected None
start date / float / dur when it starts to apply (default: the start of the sim): a date, a bare number (a calendar year if the sim has a calendar, else a time in its unit from 0), or a duration, that long after the start of the sim; the same as when=ss.schedule(start=...) None
stop date / float / dur when it stops applying, likewise (default: never; a stop after the end of the sim never stops it) None
when schedule / func when it applies, on time alone, which can be read before the run: ss.schedule(start=..., stop=...) for a window (a stop after the end of the sim never stops it; a bare number is a calendar year if the sim has a calendar, else a time in its unit from 0), ss.schedule() with times or how often for those steps only, or a function of the date of each step, true on the steps it applies (e.g. lambda now: now.month in [6, 7, 8], in a sim with a calendar); a condition on anything else goes in who= None
until Cond / func / dur how long it stays on once who= (or when=) selects someone: until a condition holds, as for a lockdown that starts at one level of cases and ends at a lower one (with who=; while both hold, who= wins); or a duration, at least this long, as a rule that is lifted only after a while (a bare number is in the sim’s unit) None
name str the name of the modifier None

Examples

S, I, R = ss.states(3)
sir = ss.Disease(infection=S >> I @ 0.3*I, recovery=ss.Transition(I, R, dur=10), init_prev=0.01)
masks = ss.modify(sir.pars.beta, multiply=0.6, start=30)
sim = ss.Sim(sir, interventions=masks, stop=100).run()

# Schools closed from day 200 to day 260 (in a sim with a calendar, that long after its start)
closure = ss.modify(sir.pars.beta, multiply=0.7, start=ss.days(200), stop=ss.days(260))

# Changes at given times, each holding until the next; before the first, the quantity has its own value
lockdown = ss.modify(sir.pars.beta, multiply=ss.timeseries({30: 0.5, 60: 1.0}), start=30)

# Each place on its own: contacts cut by 40% for at least 14 days once a week's cases pass 200 per 100,000
npi = ss.modify(sir.pars.beta, multiply=0.6, who=sir.infection.incidence(over=ss.days(7), by='patch') > 200e-5, until=ss.days(14))

# A lockdown that starts when 2% of people are infectious and ends when 1% are
lockdown = ss.modify(sir.pars.beta, multiply=0.5, who=sir.I.frac >= 0.02, until=sir.I.frac <= 0.01)

# Condoms, 90% effective against gonorrhea, used in a fraction of acts that grows over time, on one network
use = ss.timeseries({2000: 0.05, 2020: 0.3})
condoms = ss.modify(ng.infection, efficacy=0.9, frac=use, network='sexualnet')

# A member of a disease, with the rest of its natural history
class Measles(ss.Disease):
    S, I, R = ss.states('S I R')
    infection = S >> I @ 0.5*I
    recovery = I >> R @ ss.days(10)
    fading = ss.modify('rel_trans', multiply=0.5**(I.time_in/ss.days(3)), who=I)

# Summer only, every year
summer = ss.modify(sir.pars.beta, multiply=1.2, when=lambda now: now.month in [6, 7, 8])

check_applied

connectors.check_applied(sim)

Raise a ValueError for any modifier or efficacy of a product that nothing in the sim would apply, naming it and why

Called once by sim.init(), after every module has registered its modifiers in sim.modifiers (by module, kind of quantity, and name). For each quantity modified, the module it belongs to says whether it reads it: a declared module from its graph (unapplied()), and a module written as code from what its own code reads (ss.solvers.Effects.unapplied_par(), and for a disease ss.solvers.Undeclared.unapplied()). A network’s contacts are read by every transmission over it. It costs one pass over the quantities modified.

to_time

connectors.to_time(sim, val)

Convert a time (a date, a number, or a duration) to the same kind of time as the sim’s timeline

How a bare number is read is decided once, from the sim’s start (see ss.timeline.calendar_of()): if the sim has a calendar (its start is a date or a year), a number is a calendar year (2005 is the start of 2005, 2005.5 the middle of it); otherwise, it is a time in the sim’s unit from 0. A duration is that long after the sim’s start if the sim has a calendar (ss.days(30) is 30 days in), and with none a point on the sim’s own axis, counted from 0 as sim.t.tvec is (ss.days(30) is day 30, the same when the start is 0); see ss.Timeline.to_time().
