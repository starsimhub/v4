Description

internals.presentation.Description()

The description of a model (see sim.describe()): sections, each with a title and rows of a key, its text, and what was guessed

Shown in color in a terminal, as tables in a notebook, and as plain text otherwise (str(desc)), with each guess in brackets at the end of its line.

Diagram

internals.presentation.Diagram()

A diagram as the text of a Mermaid flowchart (https://mermaid.js.org), which a notebook draws

It is a string, so print() gives the text, and it can be pasted into anything that draws Mermaid (GitHub, Quarto, most Markdown viewers). In JupyterLab (4.1 or later) and in a page built by Quarto, it is drawn as a Markdown block.

internals.presentation.Presentation.edges()

Each transition as (source, destination, name, kind, p), with None for ss.null; a transition to every state (ss.death()) is one edge from each

p is the share that takes this destination, for a transition with p= (None for the one that takes the rest), and False for one without.

flow_terms
internals.presentation.Presentation.flow_terms(engine=None)

Each flow of the compartmental form, with symbolic parameter names, for equations() and for exports

Returns the name of each compartment (a state, or its stages as I_1, I_2, …), and for each flow its transition, the compartment it leaves (or None), the flow out of it, and the compartments it enters, each with its share of the flow (none for an outflow)
