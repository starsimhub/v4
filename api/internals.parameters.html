internals.parameters

internals.parameters

Parameters: the container of a module’s or sim’s parameters (ss.Pars), and values that vary in time (ss.timeseries, ss.seasonal); values by level (ss.by) are in by.py

They exist so that a parameter is checked when set, and can vary in the same way however a model is written or run.

Used with: agents and compartments; declared and coded modules

lock
internals.parameters.Pars.lock(locked=True)

Lock the parameters, so that setting a key that doesn’t exist raises an error

Parameters are locked when the sim is initialized, so that e.g. a typo in sim.pars['rand_sed'] = 2 raises an error rather than silently doing nothing. Use pars.lock(False) to unlock, or pars.update(create=True) to add a new key.

update
internals.parameters.Pars.update(pars=None, create=False, **kwargs)

Update internal dict with new pars.

A new value replaces the old one, except that a declared parameter (ss.par) takes the value and keeps its name and bounds, a bare number for a typed value keeps its unit, and a single value for a distribution sets its main parameter (see _update_dist()). To change one parameter of a distribution, use its own method, e.g. pars.dur_inf.set(mean=8).

seasonal

internals.parameters.seasonal(mean=1.0, amplitude=0.0, peak=0.0, period=None)

A value with a yearly cycle: mean × (1 + amplitude × cos(2π(t − peak))), with t in years (or another period)

It can be used wherever a value or a function of the sim can. In a sim with no dates, time starts at the beginning of a year.

Parameters

Name Type Description Default
mean any the mean over the year: a number or a typed quantity 1.0
amplitude float the size of the cycle relative to the mean (0.3 means from 70% to 130% of it) 0.0
peak str / float / dur when the value is highest: a month (its middle is used), a fraction of the year (0 to 1), or a time of year (e.g. ss.days(142)) 0.0
period dur / float the length of the cycle (default a year), e.g. ss.years(0.5) for two peaks a year, the first at peak; a number is in years None

Examples

beta = ss.seasonal(mean=0.3, amplitude=0.4, peak='January')
S, I = ss.states(2)
sis = ss.Disease(infection=S >> I @ beta*I, recovery=ss.Transition(I, S, dur=10), init_prev=0.01)
sim = ss.Sim(sis, start='2020-01-01', stop='2023-01-01').run()
rains = ss.seasonal(amplitude=0.5, peak='April', period=ss.years(0.5)) # Peaks in April and October

timeseries

internals.parameters.timeseries(
    data,
    values=None,
    interpolation='step',
    period=None,
)

A value that varies in time, given at some times and interpolated between them

It can be used wherever a value or a function of the sim can: as a rate or a duration, as the amount of ss.modify(), or as the coverage or capacity of a delivery. Before the first time the first value is used, and after the last time the last, so a value that holds from before the sim needs no time of its own: give it at the first time you have. A bare time is read as the sim reads any (see ss.timeline): a calendar year if the sim has a calendar (a start that is a date or a year), however small, else a time in its unit from 0; a duration is a time after the start (e.g. ss.days(91), 91 days in; with no calendar, day 91, the same when the start is 0). A bare value is read in the module’s unit, as any other; to give the values a unit, put the series in a type (ss.peryear(ss.timeseries(...)), a series of rates per year), or give each value one.

Parameters

Name Type Description Default
data dict / str / dataframe / list the value at each time, as a dict, a dataframe (the first column is the time, the second the value), or the name of a file holding one; or the times, with the values as the second argument (ss.timeseries(times, values)). A time is a date, a bare number (a calendar year in a sim with a calendar, e.g. 2030, and otherwise a time in the sim’s unit from 0), or a duration, that long after the start of the sim required
values list the values, if data is the times None
interpolation str how to interpolate: ‘step’ (each value holds until the next, as for a policy that starts on a date), ‘linear’ (a steady change from each value to the next, as for coverage that is scaled up), or ‘cosine’ (a smooth S-shaped change between each value and the next, as MEmilio’s dampings) 'step'
period dur if given, the series repeats with this period, measured from its first time (e.g. ss.years(1) for a yearly pattern given over one year); keyed by durations, they are the times within each cycle, from the start of the sim (e.g. {ss.years(k/12): v[k] ...}, one value per month) None

Examples

beta = ss.timeseries({'2020-01-01': 0.3, '2020-03-15': 0.1, '2020-06-01': 0.2})
decay = ss.timeseries({0: 0.1, 91: 0.2, 183: 0.15, 274: 0.1}, period=ss.days(365)) # The same each year, in a sim in days with no calendar
season = ss.timeseries({ss.months(k): v for k,v in enumerate([1, 2, 4, 2, 1, 1])}, period=ss.months(6)) # Twice a year from the sim's start, with or without a calendar
mortality = ss.peryear(ss.timeseries({2000: 0.05, 2020: 0.02})) # Rates per year: 0.05 before 2000, and 0.02 after 2020
S, I, R = ss.states(3)
sir = ss.Disease(infection=S >> I @ beta*I, recovery=ss.Transition(I, R, dur=10), init_prev=0.01)
sim = ss.Sim(sir, start='2020-01-01', stop='2020-09-01').run()

now

internals.parameters.now(val)

The value now of a value that varies, bound to a module (see Pars.bind()) whose sim is initialized; else None. If its values are typed (e.g. ss.timeseries({2000: ss.peryear(0.1), 2010: ss.peryear(0.2)})), it is typed (an ss.peryear), as a typed value in a module’s parameters is, so .to_prob() and .to_dt() work on either (see typed_now()); otherwise a number in the sim’s unit, as number_now() gives it

number_now

internals.parameters.number_now(val, sim, cache=None)

A value as code reads it now, as plain numbers in the sim’s unit (see ss.Module._value()): a typed value as a number, a value that varies in time at the current time, and a value by level for each level; cache keeps the typed values converted (see ss.solvers.convert()). Unlike ss.Module.current_value(), which gives a module’s parameter with its modifiers, in its own type.
