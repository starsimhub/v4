internals.parameters

internals.parameters

Parameters: the container of a module’s or sim’s parameters (ss.Pars), and values that vary by level or in time (ss.by, ss.timeseries, ss.seasonal)

They exist so that a parameter is checked when set, and can vary in the same way however a model is written or run.

Used with: agents and compartments; declared and coded modules

Classes

Name Description
Pars Dict-like container of parameters
Static What an expression of parameters alone is evaluated with, outside the engine: see const_value()
TimeValue Base class for values that vary in time: called with the sim, they return the value at the current time

by_func A value for each level of one dimension from a function of the sim, ss.by(patch=fn), where fn(sim) gives one value per level
seasonal A value with a yearly cycle: mean × (1 + amplitude × cos(2π(t − peak))), with t in years (or another period)
timeseries A value that varies in time, given at some times and interpolated between them

internals.parameters.Pars.lock(locked=True)

Lock the parameters, so that setting a key that doesn’t exist raises an error

Parameters are locked when the sim is initialized, so that e.g. a typo in sim.pars['rand_sed'] = 2 raises an error rather than silently doing nothing. Use pars.lock(False) to unlock, or pars.update(create=True) to add a new key.

by

internals.parameters.by(table=None, dims=None, **kwargs)

A value for each level of one or more stratifications, or of people’s own properties

With several dimensions as keywords, the value of a group is the product of its value in each. A table gives every combination directly: it has a column for each stratification (holding the labels of its levels) and a column of values.

A property of people that is not a dimension of the sim (e.g. sex, read from people.female, or a property such as urban) is read from each person, as agents: give its values by name (sex=dict(female=..., male=...)), or as a table. A column of numbers in a table holds the lower edges of bins (the last one open-ended), so a table by single year of age works as agents whatever the model’s age groups (a compartmental run needs bins whose edges are those of the groups, or coarser: a group split by a bin has no one value, and is refused); a row whose key is None gives the value for people with no value of the property, who otherwise get the mean over the levels.

Parameters

Name Type Description Default
table df / array a dataframe (or a dict of columns) with a column per stratification or property and a column named value; or, with dims, an array with one axis per dimension None
dims list the dimensions of the axes of an array given as table None
kwargs dict each dimension, and one value per level (a list, by position), or a dict of values by label (or, for one dimension, by lower bin edge if the keys are numbers, as in a table: ss.by(age={0: 0, 15: 0.3})) {}

A value may itself vary in time (ss.timeseries or ss.seasonal), in the keyword and table forms.

Arithmetic with a number, or with another ss.by over the same levels, gives an ss.by; anything else (e.g. tables by different bins, a count, or np.minimum(by, 1)) is an expression, worked out where it is used.

Examples

beta = ss.by(age=[0.08, 0.05, 0.03])
beta = ss.by(age=[0.08, 0.05, 0.03], sex=[1.0, 0.8]) # One per age group and sex: the product
init = ss.by(pd.DataFrame(age=['child', 'adult'], patch=['north', 'north'], value=[10, 5])) # Every other combination is 0
pop = ss.by([[3000, 1000], [5000, 2000]], dims=['age', 'patch']) # Ages by row, places by column
beta = ss.by(age=[ss.timeseries({2020: 0.08, 2021: 0.04}), 0.05, 0.03]) # Children's value changes in 2021
mu = ss.by(sex=dict(female=0.008, male=0.011)) # From people.female, with or without a dimension by sex
p = ss.by(dict(age=range(15, 50), value=vals)) # By single year of age (bins with these lower edges)

seasonal

internals.parameters.seasonal(mean=1.0, amplitude=0.0, peak=0.0, period=None)

A value with a yearly cycle: mean × (1 + amplitude × cos(2π(t − peak))), with t in years (or another period)

It can be used wherever a value or a function of the sim can. In a sim with no dates, time starts at the beginning of a year.

Parameters

Name Type Description Default
mean any the mean over the year: a number or a typed quantity 1.0
amplitude float the size of the cycle relative to the mean (0.3 means from 70% to 130% of it) 0.0
peak str / float / dur when the value is highest: a month (its middle is used), a fraction of the year (0 to 1), or a time of year (e.g. ss.days(142)) 0.0
period dur / float the length of the cycle (default a year), e.g. ss.years(0.5) for two peaks a year, the first at peak; a number is in years None

Examples

beta = ss.seasonal(mean=0.3, amplitude=0.4, peak='January')
S, I = ss.states(2)
sis = ss.Disease(infection=S >> I @ beta*I, recovery=ss.Transition(I, S, dur=10), init_prev=0.01)
sim = ss.Sim(sis, start='2020-01-01', stop='2023-01-01').run()
rains = ss.seasonal(amplitude=0.5, peak='April', period=ss.years(0.5)) # Peaks in April and October

timeseries

internals.parameters.timeseries(data, values=None, mode='constant', period=None)

A value that varies in time, given at some times and interpolated between them

It can be used wherever a value or a function of the sim can: as a rate or a duration, as the amount of ss.modify(), or as the coverage or capacity of a delivery. Before the first time the first value is used, and after the last time the last.

Parameters

Name Type Description Default
data dict / str / dataframe / list the value at each time, as a dict, a dataframe (the first column is the time, the second the value), or the name of a file holding one; or the times, with the values as the second argument (ss.timeseries(times, values)). A time is a date, or a number: a calendar year from 1900 on (e.g. 2030), and otherwise a time in the sim’s unit (in a sim with dates, that long after the start) required
values list the values, if data is the times None
mode str how to interpolate: ‘constant’ (each value holds until the next), ‘linear’, or ‘cosine’ (a smooth S-shaped change between each value and the next, as MEmilio’s dampings) 'constant'
period dur if given, the series repeats with this period, measured from its first time (e.g. ss.years(1) for a yearly pattern given over one year) None

Examples

beta = ss.timeseries({'2020-01-01': 0.3, '2020-03-15': 0.1, '2020-06-01': 0.2})
decay = ss.timeseries({0: 0.1, 91: 0.2, 183: 0.15, 274: 0.1}, period=ss.days(365)) # The same each year
S, I, R = ss.states(3)
sir = ss.Disease(infection=S >> I @ beta*I, recovery=ss.Transition(I, R, dur=10), init_prev=0.01)
sim = ss.Sim(sir, start='2020-01-01', stop='2020-09-01').run()

internals.parameters.starting(val)

A starting value (init=, init_n=, or init_prev=, or a parameter holding one), where an ss.by given by label may leave levels out, which start at 0, e.g. init_n=dict(I=ss.by(patch={'Nairobi': 10})); a rate or other parameter by label needs every level, since a missing one there is more likely a mistake.
