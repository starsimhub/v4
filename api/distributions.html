distributions

distributions

The distributions to choose from: ss.uniform, ss.normal, ss.poisson, and so on, each a random-number-safe ss.Dist

These exist so that a model can use any distribution for a parameter or a draw, with the same random numbers for the same agent across scenarios. How they work is in ss.dists. As agents, they are drawn for each agent; in a compartmental run, most are read for what they say about the group, such as their mean.

Used with: agents and compartments; declared and coded modules

choice

distributions.choice(a=2, p=None, replace=True, **kwargs)

Random choice between discrete options

The probabilities can differ by agent: give p as a 2D array with one row per agent drawn for (or a function returning one), and one column per choice. Each row is normalized to sum to 1. Each agent’s choice is found from their own random number by the inverse CDF of their own row, so the draw is one vectorized call, and keeps common random numbers: an agent’s choice doesn’t depend on who else is drawn for, or on other agents’ probabilities.

Parameters

Name Type Description Default
a int or array the number of choices, or the choices themselves (default 2) 2
p array / func if supplied, the probability of each choice (default, 1/a for a choices); or a 2D array (or a function returning one) with a row of probabilities (or weights) for each agent None
replace bool whether an option can be chosen more than once (default True) True

Examples

# Simulate 10 die rolls
ss.choice(6, strict=False)(10) + 1

# Choose between specified options each with a specified probability (must sum to 1)
ss.choice(a=[30, 70], p=[0.3, 0.7], strict=False)(10)

# A row of probabilities per agent: here by age group, from a table of age groups × choices
table = np.array([[0.7, 0.2, 0.1], [0.3, 0.4, 0.3]])
def p_by_age(self, sim, uids):
    return table[(sim.people.age[uids] >= 18).astype(int)]
method = ss.choice(a=['none', 'pill', 'iud'], p=p_by_age) # In a module's __init__()
chosen = self.method.rvs(uids) # In its step()

Note: although Bernoulli trials can be generated using a=2, it is much faster to use ss.bernoulli() instead.

choose_n

distributions.choose_n(n=1, weights=None, die=False, **kwargs)

Choose exactly n agents (without replacement) from a set of candidate UIDs

Like ss.bernoulli, use the filter() method, which returns the chosen UIDs. One random number is drawn per candidate (based on its slot), and the n candidates with the smallest numbers are chosen. This means that if the candidates change slightly (e.g. between two scenarios), most of the same agents are still chosen (unlike e.g. ss.choice(replace=False)).

If weights are supplied, candidates are chosen with probability proportional to their weight, via the Efraimidis–Spirakis key (1-u)**(1/w). This is computed as -log(1-u)/w, so the n smallest are chosen as before, and equal weights give the same agents as no weights. Candidates with zero weight are never chosen, so fewer than n UIDs are returned if fewer than n candidates have nonzero weight.

Parameters

Name Type Description Default
n int / func the number of agents to choose (or a function returning it); if more than the number of candidates, all are chosen 1
weights array / func if supplied, the relative weight of each candidate (or a function returning them), matching the UIDs passed to filter() None
die bool if True, raise an exception if fewer than n agents can be chosen (default: False) False

Examples

# Seed exactly 20 infections of a disease written as code
sir = ssl.AgentSIR(init_prev=ss.choose_n(20))

# Choose 5 agents, weighted by age
chooser = ss.choose_n(5, weights=lambda self, sim, uids: sim.people.age[uids])

histogram

distributions.histogram(
    values=None,
    bins=None,
    density=False,
    data=None,
    **kwargs,
)

Draws from a histogram, uniform within each bin, e.g. ages from the number of people in each age group

Note: unlike other distributions, the parameters of this distribution can’t be modified after creation.

Parameters

Name Type Description Default
values array the probability (or count) of each bin None
bins array the edges of each bin None
density bool treat the histogram as a density instead of counts; only matters with unequal bin widths, see numpy.histogram and scipy.stats.rv_histogram for more information False
data array if supplied, compute the values and bin edges using this data and np.histogram() instead None

Note: if the length of bins is equal to the length of values, they will be interpreted as left bin edges, and one additional right-bin edge will be added based on the difference between the last two bins (e.g. if the last two bins are 40 and 50, the final right edge will be added at 60). If no bins are supplied, then they will be created as integers matching the length of the values.

The values can be supplied in either normalized (sum to 1) or un-normalized format.

Examples

# Sample from an age distribution
age_bins = [0,    10,  20,  40,  65, 100]
age_vals = [0.1, 0.1, 0.3, 0.3, 0.2]
h1 = ss.histogram(values=age_vals, bins=age_bins, strict=False)
h1.plot_hist()

# Create a histogram from data
data = np.random.randn(10_000)*2+5
h2 = ss.histogram(data=data, strict=False)
h2.plot_hist(bins=100)

multi_random

distributions.multi_random(names, *args, crn=None, **kwargs)

Random numbers for pairs (or larger groups) of agents, e.g. one for each edge of a network in a transmission

It holds an ss.random() for each member of the pair, and combines their numbers, so the number for a pair depends on both agents and, with common random numbers, not on which other pairs are drawn for. For the manual version, see ss.distributions.combine_rands(); this class should be used in almost all cases.

ppf
distributions.poisson.ppf(rands)

Fast inverse-CDF sampling for the common-random-number (ppf) path.

SciPy’s generic discrete ppf is very slow (it root-finds per element), and for CRN draws it is called every time an ss.poisson is sampled by UID. For a scalar mean we instead precompute the CDF once and map each uniform via np.searchsorted, which is 30-60x faster and produces bitwise-identical results. An array-valued mean is inverted by ss.solvers.backends.draws (SciPy’s above a mean of 30, and for unusual values).

Its values are those of ss.uniform() with its defaults, but it cannot be scaled or given a unit, and it can be given a dtype (e.g. float32); for a value between bounds, or with a unit, use ss.uniform().

combine_rands

distributions.combine_rands(a, b)

Combine two arrays of random integers into one array of random numbers between 0 and 1, e.g. one for each pair of agents

See ss.multi_random(), which is the version to use in almost all cases.

Inputs must be uint64: signed integers would produce output in [-0.5, 0.5] rather than [0, 1], so they raise an error rather than being cast, since casting would silently copy the array. To reinterpret existing bits for free, use arr.view(np.uint64).

Parameters

Name Type Description Default
a array array of random uint64 integers between 0 and np.iinfo(np.uint64).max, as from ss.randint(low=0, high=np.iinfo(‘uint64’).max, dtype=np.uint64) required
b array ditto, same size as a required

Returns

Name Type Description
A new array of uniformly distributed random numbers in [0, 1], the same size as a and b

erlang

distributions.erlang(k=1, mean=1.0, **kwargs)

Erlang distribution: the sum of k exponential stages, given by its number of stages and its mean

This is ss.gamma with an integer shape: ss.erlang(k=3, mean=10) is ss.gamma(shape=3, scale=10/3). As a dwell time, it has an exact compartmental form (k sub-stages), so runs the same under every solver.

Parameters

Name Type Description Default
k int the number of stages (the shape parameter) 1
mean float the mean of the distribution (not of each stage; with loc=, a shift, the mean of the whole distribution) 1.0
kwargs dict passed to ss.gamma()

Examples

ss.erlang(k=3, mean=ss.days(10))
