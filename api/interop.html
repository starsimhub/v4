interop

interop

Import models from other frameworks

ss.import_from(filename, format=...) reads another framework’s model into a sim; see v4_design/design/16-interop.md. Each importer reads its format into an ss.io.Source, and ss.io.build() writes that as Starsim code by the same rules for every format (ss.io.write()) and runs the code to make the sim: the code is kept in sim.imported.code, how each rate was read is printed, and what could not be translated is listed as ss.errors.ImportIncomplete and kept in sim.imported.

Source

interop.Source(name, format, file=None)

A model read from another framework, before it is built into a sim

An importer fills this in from the source, then build() writes it as Starsim code (write()) and runs the code to make the sim. Every rate is an expression in Python syntax, in which a state’s name means the number of people in it.

Parameters

name str the model’s name required
format str the format it was read from, e.g. ‘emulsion’ required
file str the file it was read from, if any None

build

interop.build(sources, verbose=None, **kwargs)

Build a sim from one or more models read from another framework, by running the code write() gives

Each source becomes a disease. Prints how each flow was read and, as ss.errors.ImportIncomplete, what could not be translated; both are kept in sim.imported, with the code (sim.imported.code), which is the user’s to keep and change (e.g. sc.savetext('model.py', sim.imported.code)).

to_hub

interop.to_hub(
    msim,
    targets,
    origin_date=None,
    by=None,
    every='week',
    output_type='quantile',
    quantiles=hub_quantiles,
    location=None,
)

The runs of a MultiSim as a submission to a hub (in the hubverse format): each target, by scenario, location, and period

Each scenario (the label of its sim) is its own scenario_id, and the periods are counted from origin_date. A target’s name says what it is: one starting “cum” is the total since the origin date, one starting “peak size” is the largest value of a period (with no horizon), and any other is a flow’s total over each period, or a count at its end.

Parameters

Name Type Description Default
msim ss.MultiSim the runs required
targets dict the hub’s name (or a list of names) for each result, e.g. dict(incidHosp=['inc hosp', 'cum hosp', 'peak size hosp']) required
origin_date date the date the periods are counted from (default: the start of the runs); for runs without dates, a time, which the origin_date column then holds None
by str the dimension whose levels are the locations (default: one location, the total) None
every str the period: ‘day’ or ‘week’ (of the sim’s steps, which must then be days) 'week'
output_type str / list ‘quantile’ (of the runs of each scenario), ‘sample’ (each run, by its position in its scenario), or both 'quantile'
quantiles list the quantiles (default: the 23 that the US hubs ask for) hub_quantiles
location str the name of the single location, if by is not given None

Returns a long dataframe with columns origin_date, scenario_id, location, target, horizon, output_type, output_type_id, and value.

Example:

msim = ss.parallel(baseline=s1, lockdown=s2, n_runs=20)
hub = ss.io.to_hub(msim, targets=dict(infection=['inc inf', 'cum inf']), origin_date='2020-03-01', by='patch')

write

interop.write(sources, **kwargs)

The Starsim code of one or more models read from another framework

Each source becomes a declared disease (ss.Disease), with its parameters, states, and transitions as variables; the code ends with the sim (sim = ss.Sim(...)). It says where the model came from, how each rate was read, and what was not translated. This is the code build() runs, kept as sim.imported.code.

Parameters

Name Type Description Default
sources Source / list | the model, as read by an importer, or several (e.g. one for each state machine) | required |
kwargs dict passed to ss.Sim(), after each source’s config {}

Returns

Name Type Description
An sc.objdict of the code, how each flow was read (choices, a line each), and what was guessed about each transition (guessed, by disease and transition)
