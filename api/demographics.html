demographics

demographics

Births, deaths, migration, and pregnancy

These exist so that the population can change during a run. ss.Births and ss.Deaths are written as code, ss.birth() and the like declare the same flows for the whole population, and ss.Pregnancy is declared, so that conception and delivery are transitions that other modules can modify or respond to.

Used with: agents and compartments; declared and coded modules

Births

Create births based on rates, rather than based on pregnancy.

Births are generated using population-level birth rates that can vary by year. The number of births per timestep is determined by applying the birth rate to the current population size; each newborn’s parent (people.parent) is a woman of reproductive age (min_age to max_age).

Note: CRN safe.

Deaths

demographics.Deaths(
    pars=None,
    rel_death=_,
    death_rate=_,
    rate_units=_,
    metadata=None,
    lifetable=None,
    **kwargs,
)

Configure disease-independent “background” deaths.

The probability of death for each agent on each timestep is determined by the death_rate parameter and the time step. The default value of this parameter is 0.01, indicating that all agents will face a 1% chance of death per year.

However, this function can be made more realistic by using a dataframe for the death_rate parameter, to allow it to vary by year, sex, and age. The separate ‘metadata’ argument can be used to configure the details of the input datafile.

Alternatively, it is possible to override the death_rate parameter with a bernoulli distribution containing a constant value of function of your own design.

Note: CRN safe.

Parameters

Name Type Description Default
pars dict with arguments including: rel_death: constant used to scale all death rates death_rate: float, dict, or pandas dataframe/series containing mortality data lifetable: instead of death_rate, life tables (ss.lifetable): one, one for each sex (dict(female=..., male=...)), or one (or one for each sex) for each year from which it holds ({2000: ..., 2010: ...}); each is the death rate of each of its age bands, per person, so deaths follow the table of the year and each person’s sex and age as time goes on (ss.death(lifetable=) instead draws each person’s age at death once, from one table) rate_units: what the rates are per: 1000 (or 1e-3) for per 1,000 people, 1 for per person; by default, per 1,000 if the largest rate is above 1, otherwise per person, with a warning if it could be either (see ss.demographics.infer_rate_units()). The crude mortality rate result (cmr) is in the same units. None
metadata data about the data contained within the data input. “data_cols” is is a dictionary mapping standard keys, like “year” to the corresponding column name in data. Similar for “sex_keys”. None

Demographics

demographics.Demographics(name=None, label=None, **kwargs)

Base class for demographic modules.

A demographic module typically handles births/deaths/migration and takes place at the start of the timestep, before networks are updated and before any disease modules are executed. See ss.Births, ss.Deaths, and ss.Pregnancy for built-in implementations. Demographic modules modify the ss.People population and can interact with ss.Network objects (e.g. to add newborns to contact networks).

Flows

demographics.Flows(transitions, **kwargs)

Births, deaths, and migration declared for the whole population, as ss.Sim(demographics=[ss.birth(...), ss.death(...)]) gives them

Every declared disease’s people are born and die by them, once, under every solver: they become transitions of the first declared disease (or the first with the state that births name), whose people are everyone’s, since as agents the diseases share the people, and in a compartmental run with several declared diseases, their states are tracked jointly (see ss.solvers.choose.init_flows()). With no declared disease, the sim adds one of everyone alive to hold them (ss.demographics.Population), so they are a declared model like any other. This class is not usually used directly.

Note: CRN safe as agents.

Pregnancy

demographics.Pregnancy(pars=None, fetus='auto', metadata=None, **kwargs)

Pregnancy, as declared states and transitions

Everyone is in NP (not pregnant: men and children too) or P (pregnant). Gestational age is P.time. Conception is one transition, so contraception, HIV, or LAM are modifiers of it (ss.modify(preg.conception, multiply=...)). A pregnancy ends in an abortion (at once, with p_abortion), a miscarriage or stillbirth (a hazard before or after loss_threshold), a maternal death (antepartum), or a delivery at the end of a dwell of dur_pregnancy. Each delivery gives embryos_per_pregnancy children (birth): as agents, new agents whose parent is the mother, placed in each declared module’s state given by its own ss.birth(per=preg.delivery) (or else its first state). Children die before the age of 1 at infant_rate (infant_mortality; 0 by default). It runs as agents under solver='auto'; a compartmental solver named explicitly runs a small approximate form (see compartmental_form()).

For other modules, preg.delivery happens to the mother, and to her fetuses (if they are agents: see _init_fetus()) before they are born, so a death of a fetus where=preg.delivery is a stillbirth; preg.birth happens to the newborns, so a neonatal death is where=preg.birth.

As agents, a live birth starts breastfeeding (lactating, with p_breastfeed), or restarts it for a woman breastfeeding already; it ends after dur_breastfeed, or at once if a child of hers dies before the age of 1. It is a state of each woman rather than one of the module’s exclusive states (NP, P), since it overlaps the next pregnancy. A BreastfeedingNet pairs each newborn with a mother who breastfeeds, and ends the pair when she stops.

As agents, a woman who leaves P (a delivery, a loss, or an abortion) faces conception again in the same step, for what is left of it (half a step); the children and records of a delivery (ti_delivered, since_birth, lactating) are made first, so a rate or a modifier that reads them sees this delivery. A rate given as a function (e.g. an override of conception_rate()) can be called more than once a step, for those who arrive in NP within it, so it should not draw random numbers.

Its parameters are listed in __init__(); code reacts to its events with add_callback(), e.g. preg.add_callback(preg.birth, fn). Its states and results are P (pregnant), ti_P, the scheduled delivery ti_exit_P (set_delivery() reschedules it), and the flows conception, birth, miscarriage, stillbirth, and abortion; as agents, lactating (breastfeeding).

Note: CRN safe as agents.

Examples

preg = ss.Pregnancy(fertility_rate=ss.freqperyear(80))
sim = ss.Sim(demographics=preg, n_agents=5000, start=2000, stop=2010, dt=ss.months(1)).run()
sim.results.pregnancy.conception.sum()

# Nigeria's age-specific fertility rates, from the UN
preg = ss.Pregnancy(fertility_rate='Nigeria')

# Lactational amenorrhea: fewer conceptions while breastfeeding, in the first 6 months
lam = ss.modify(preg.conception, multiply=0.1, where=preg.lactating & (preg.since_birth < ss.months(6)))

burnin_plan
demographics.Pregnancy.burnin_plan(engine)

burnin=True (the default): women pregnant at the start. Each woman who could conceive has the chance of having conceived in the mean duration of a pregnancy before the start, at her conception hazard then (1 - exp(-h*dur)), at a step uniform over it, and is run forward by the pregnancy’s own transitions (abortion, losses, and delivery, with no births), so the start has the gestational ages and the first steps their deliveries. In the compartmental form, the same share of each group, less the abortions and the losses on the way, is spread evenly over gestation (see ss.solvers.Compartmental.backfill_burnin()).

compartmental_form
demographics.Pregnancy.compartmental_form(sim)

The small compartmental form, used only when a compartmental solver is named (solver='auto' runs a pregnancy as agents): the states NP and P, conception, abortion, maternal deaths, and the delivery at the end of dur_pregnancy (a fixed delay, or Erlang stages for a distribution), with n children per delivery (ss.birth(per=preg.delivery)). preterm_risk
demographics.Pregnancy.preterm_risk(uids, rel=None)

At conception: each woman’s relative risk of preterm birth (rel_ptb), her baseline (rr_ptb) times the risk at her age (rr_ptb_age), multiplies her probability of a preterm duration (below preterm_threshold), capped at 1; the durations within the preterm and the term ones keep their shares. For dur_pregnancy as an ss.choice (the default), each duration is drawn so (one uniform number, by inverse transform), kept in weeks (dur_gestation, the gestational age at birth), and the delivery scheduled by it, as the engine schedules a dwell time (agents only)

Called again during a pregnancy, it draws the duration again: with rel, a relative risk for this draw on top of hers (e.g. an infection acquired while pregnant), which her baseline for later pregnancies does not keep. A delivery it would schedule in a step already past is taken in the next step (see set_delivery()).

Parameters
Name Type Description Default
uids uids the women required
rel float / array a relative risk for this draw only, one number or one per woman None

Example::

preg.preterm_risk(uids, rel=2.0) # Twice the risk of preterm birth, for the pregnancies these women have now

bare_rate

demographics.bare_rate(rate, name)

A crude rate of births or deaths of everyone given as a bare number, read as ss.Births and ss.Deaths read theirs: per year, and per 1,000 people if above 1, otherwise per person (see infer_rate_units()); anything else is returned as it is

Returns the rate, and a note saying how a bare number was read (None for anything else), which is said with say_bare() once the module is in a sim: a bare number is the usual way to give these rates, so it is not a warning

A time series of bare numbers is read the same way, its values together (so 40 falling to 0.5 is per 1,000 throughout).

infer_rate_units

demographics.infer_rate_units(units, rates, name, hint=None)

What the rates of ss.Births, ss.Deaths, or ss.Pregnancy are per, as a factor to multiply them by: 1e-3 for per 1,000 people, 1 for per person

With rate_units=None (the default), it is worked out from the largest rate: above 1, per 1,000 (e.g. ss.Births(birth_rate=35)); otherwise per person (e.g. ss.Births(birth_rate=0.035)). A warning says which was assumed when the largest rate could be either (from 0.1 to 1, or above 1,000); give rate_units to say which, and silence it.

Returns a dict of the rows (a number, or an array by age) by the index of each row, e.g. (2010, ‘f’), the years, and the ages (the columns, if any); None if the rates are not a dataframe or series

standardize_fertility_data

demographics.standardize_fertility_data(mod)

The fertility rates of a pregnancy module (pars.fertility_rate, with metadata for a dataframe): a rate, or by year and age, with 1-year steps and a 0 past the last age group

yearly_rows

demographics.yearly_rows(found)

Rates from rate_rows() that are estimates for single years some years apart (a named place’s UN rates, every ten years), as a row for each year between, linearly interpolated, so none is held for a decade
