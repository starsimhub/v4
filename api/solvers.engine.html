solvers.engine

solvers.engine

Not for the user: the base of the engines that run a declared model (Engine), and what they share

It exists so that the solvers read one model the same way. What it gives modules that act on a disease (Effects) applies to diseases written as code too, through ss.solvers.Undeclared.

Used with: agents and compartments; declared and coded modules

Classes

Name Description

Engine Base class for the engines that run a graph
StockCtx Evaluates result expressions (sums and ratios of states, and of flows) from the counts after the step

The number of steps between them is the shortest of a week, two weeks, four weeks, a quarter, half a year, or a year (or of 2, 5, 10, 20, … steps for a sim with no unit, or one longer than a day) that keeps them within the budget. A row of values by group then holds a flow added up over its steps, and anything else as it is at the start of them (so a ratio of states is the ratio then). See ss.Result.select().

Parameters

Name Type Description Default
npts int the number of time points required
row_bytes float the memory the results take at each time point required
budget float the most memory they may take required
name str the module whose results they are, to say so in a note None

Returns the row of each time point and the time point each row starts at, or (None, None) for every time point.
