products

products

Products: vaccines, treatments, and diagnostics, and the protection people hold from them

A product says what something does (e.g. its efficacy), and a delivery (ss.vaccinate(), ss.treat(), ss.screen()) says who gets it and when. They are kept apart so that one product can be delivered in several ways. A product written as code (administer()) runs as agents.

Used with: agents and compartments; declared and coded modules

Diagnostic

products.Diagnostic(

A diagnostic test: what ss.screen() delivers

A test gives each person one of its results: by default positive or negative, from sensitivity and specificity; or one of results=, each with its probability given the state a person is in. Each result is a result of each delivery of it, and an event (screening.positive for one delivery, hiv_rdt.positive for any delivery of the product), which triggers the steps that follow.

Note: CRN safe as agents.

Parameters

Name Type Description Default
sensitivity float / dict the probability that someone with the condition tests positive; a dict gives one for each state (each a number or an ss.by), and the test then detects being in those states. The states can be of several diseases ({hpv16.I: 0.9, 'hpv18.CIN': 0.95}), and the boolean states of a disease written as code ('hpv16.cin'); delivered with disease=[...], a state with no disease ('cin') is that state of each 1.0
specificity float the probability that someone without it tests negative 1.0
results dict instead of sensitivity and specificity, the results in order of severity, most severe first, each with its probability for people in each state (a dict by state, of any disease, as for sensitivity; a number is for those with what detects= says); the last is None, everyone the others do not take. A key None in a result’s dict is for people in none of the states keyed in any result (of any disease the test is keyed by), e.g. a false positive: it is counted once, whereas a result for a state (susceptible=0.1) is one for each disease. For someone in states of several diseases, there is a result for each disease, and the most severe of them is theirs (for a positive and a negative result, each disease is detected independently) None
delay dur / dict the time from the test to the result (agents only); a dict gives one for each result None
detects Cond / func the condition the test detects (default: being in an infected state of the disease) None
cost float the cost of each delivery None
name str the name; if not given, taken from the variable the test is assigned to None
label str the label, for plots and printing None

EventSource

products.EventSource()

What a delivery and a product share as events: the people it reached on the step (screening), its outcomes (screening.positive), and their memory

Each is a condition that triggers a delivery (ss.treat(who=screening.positive)), and remembers per person whether (.ever), how often (.count), and how long ago (.since) it happened, including on the current step once the delivery that fired it has run. As agents, the memory of every event of a delivery is kept (two numbers per agent each), so it can be read after a run too, e.g. sim.interventions.screening.ever.uids; a product’s, and in a compartmental run (only .ever) any event’s, only if something in the sim reads it.

Treatment

products.Treatment(
    cure=None,
    efficacy=None,
    transition=None,
    to=None,
    moves=None,
    **kwargs,
)

A treatment: what ss.treat() delivers

A treatment can cure (cure=, once, when it is given), change rates for as long as it is held (efficacy=), or both. By default it is given to the people who are infected. A treatment that cures has the outcomes cured, failed (infected, and not cured), and unneeded (not infected), which are results and events of its deliveries.

A treatment can instead name the transitions it moves people along (moves=), usually undriven ones (cure = A + C >> S, with no @). Each person treated who is in a source of one of them moves along it with its probability (cured), or does not (failed); one in no source is unneeded. The transitions can be of several diseases, and the probability for each can differ; a modifier of an undriven transition (ss.modify(ng.cure, multiply=0.5, where=...)) multiplies the probability for the people it applies to. It is then given to the people in their sources. What happens at failure (resistance) is a transition of the disease triggered by the outcome: ss.Transition(I, R_res, where=drug.failed, p=0.05).

Note: CRN safe as agents.

Parameters

Name Type Description Default
cure float / dict the probability that treatment cures: the person leaves whichever infected state they are in for the state the disease’s recovery leads to (or to=, or the destination of transition=); 1 if neither cure nor efficacy is given. A dict gives one for each state (each a number or an ss.by), and people in other states are not cured; for a disease written as code, its boolean states (e.g. dict(precin=0.9, cin=0.9)), each cured by its clear_infection() None
efficacy dict the effects while it is held, as for ss.Vaccine (e.g. dict(transmission=0.96, mortality=0.9)) None
transition str the transition a cured person leaves by (its flow counts them), if the disease has recoveries to more than one state None
to str the state cured people go to, if the disease has recoveries to more than one state None
moves Transition / str / list / dict instead, the transitions people move along, or a dict of the probability for each (a number, ss.by, a time series, or a function of the sim; otherwise cure); a person must not be in the sources of two of one disease’s None
waning dur / box / func / dict as for ss.Vaccine, for the effects while held required
during Cond as for ss.Vaccine: held (and its effects acting) only while people are in these states, e.g. during=typhoid.acute required
cost float the cost of each delivery required
name str the name; if not given, taken from the variable the treatment is assigned to required

Examples

ablation = ss.Treatment(cure=dict(infected=0.936, cin=0.936)) # By state

kit = ss.Treatment(moves={ng.cure: 0.95, ct.cure: 0.95}) # Two diseases, one product

A cure takes people out of whichever infected state they are in (the states counted in prevalence, and those that people infected reach on the way to the state cured people go to), never only the sources of one transition (unless transition= names one out of states that are not infected, which people are then moved along).

Vaccine

products.Vaccine(efficacy=None, leaky=True, **kwargs)

A vaccine: what ss.vaccinate() delivers

Note: CRN safe as agents.

Parameters

Name Type Description Default
efficacy float / dict protection against acquisition (required); or a dict of efficacy against each of ‘acquisition’ (scales rel_sus), ‘transmission’ (scales rel_trans), ‘mortality’ (scales the death transitions), or any named transition None
waning dur / box / func / dict a duration, for protection that is lost after an exponentially distributed time with that mean; ss.box(dur=..., decay=...), full protection for a time and then (optionally) an exponential decline, under every solver; or a function of the time since delivery returning the share of protection that remains, fn(t) or fn(t, sim, uids), with t a duration (e.g. t < ss.days(180), t.years) and uids the agents who hold it (e.g. sim.people.age[uids] - t.years, their age when it was given; agents only). A delivery gives a product that fades by a shape or function again to those who hold it, restarting it. A dict gives each effect its own (e.g. dict(acquisition=ss.box(dur=ss.years(1)), transmission=None)). For other shapes under every solver (two rates in turn), write the protection as states and move people into them: see ss.Delivery’s move= required
doses list for a vaccine given in doses, the relative efficacy after each (e.g. [0.85, 1.0]); holding it then has a level per dose, and each delivery to someone who holds it gives them the next dose required
leaky bool if True (the default), everyone who receives it is partly protected (by efficacy); if False, a share efficacy of them are fully protected and the rest not at all (“all or nothing”) True
during Cond if given, it is held only while people are in these states (e.g. during=sir.I): they stop holding it when they leave them required
cost float the cost of each delivery required
name str the name; if not given, taken from the variable the vaccine is assigned to required

Examples

bcg = ss.Vaccine(efficacy=0.85, waning=ss.years(5), cost=12.50)
ss.Vaccine(efficacy=dict(acquisition=0.85, transmission=0.3))
mcv = ss.Vaccine(efficacy=0.85, leaky=False) # 85% fully protected
hpv = ss.Vaccine(efficacy=0.95, doses=[0.85, 1.0]) # The first dose gives 85% of the protection of two
bivalent = ss.Vaccine(efficacy=dict(hpv16=0.9975, hpv18=0.9975)) # Against two diseases
rtss = ss.Vaccine(efficacy=0.8, waning=ss.box(dur=ss.days(180), decay=ss.days(730))) # Full for 180 days, then declining
linear = ss.Vaccine(efficacy=0.9, waning=lambda t: np.clip(1 - t.years/5, 0, 1)) # Fading to nothing over 5 years

box

products.box(dur, decay=None, stages=10)

Protection that is full for a time, then lost at once, or (with decay=) fading exponentially: the waning= of a product

As agents, it is the share of protection left, t after delivery (1 for t < dur, then exp(-(t - dur)/decay), or 0). In a compartmental run, holding the product has levels: the box, as stages levels each left at stages/dur (Erlang stages, so the end of the box is spread over about dur/sqrt(stages)), then a level left at the rate 1/decay, so the share holding it falls as the protection of agents does.

Parameters

Name Type Description Default
dur dur how long protection is full required
decay dur the mean time it then lasts, decaying exponentially; None (the default) for none: it ends with the box None
stages int the number of levels of the box in a compartmental run 10

Examples

rtss = ss.Vaccine(efficacy=0.8, waning=ss.box(dur=ss.days(180), decay=ss.days(730)))
net = ss.Vaccine(efficacy=0.9, waning=ss.box(dur=ss.years(3))) # Full for three years, then none
