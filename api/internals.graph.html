internals.graph

internals.graph

Not for the user: the graph of one module: its states, transitions, and parameters, collected, named, completed with defaults (each guess recorded), and checked

It exists as the one description of a declared model, which every solver runs and describe() shows, so that a model can be written once.

Used with: agents and compartments; declared modules

The states and transitions of one module

The graph is built when the module is constructed. It names everything, works out which states are people and which transitions are transmissions (from their rates), turns inline values into named parameters, and checks the result. Every guess is recorded, in graph.guessed and in the guessed of each state and transition.

This class is not usually used directly: see ss.Disease.

resolve_acquisition
internals.graph.Graph.resolve_acquisition()

Work out which transitions are an acquisition of the disease, which rel_sus, a product’s efficacy against acquisition, and ss.treat act on

A contact-mediated transition is one. So is any other transition of people out of the first state that is not an outflow, whatever its rate (a bite rate, an EIR, a count of bacteria), unless a transition out of that state is contact-mediated, which is then the acquisition (so S -> V alongside S -> I @ beta * I is a vaccination). acquisition= on the transition says it outright.

resolve_derived
internals.graph.Graph.resolve_derived()

Which states are infected, and their results. The infected states are those the model says are infected (marked ss.State(infected=True), or in its own result infected = E + I), exactly; or, if it says none are, those of a force of infection: the states people are infected into, and the sources (E and I in S >> E @ beta*I). With neither, as in a staged condition such as a cancer, no state is infected. Each state’s infected is set to match, and the infected states give the results infected, the number in them, and prevalence, their fraction of the people in every state, unless the module defines its own of that name, or has a state called infected (whose count has the name: it can define its own prevalence)

resolve_people
internals.graph.Graph.resolve_people()

Which states are people: every state, unless it is declared a count (ss.State(people=False), e.g. mosquitoes or bacteria in the water); and the first state, where people are unless they are put elsewhere: default_state= if given, else the state named S or susceptible (in any case), else the one state transmission infects people from, else the first state of people made (states are kept in the order they were created: see resolve_states()), which describe() shows as a guess. Not the state a birth goes to (ss.birth(NB) says where births go, not where everyone starts), nor the order of the transitions

resolve_rest
internals.graph.Graph.resolve_rest()

Work out where the people not given an initial state start: the first state, unless it is given an initial value of its own, which is then kept (init=dict(S=0.1, I=1e-4) starts 10% susceptible). Then it is the one state of people with no initial value, with a note in guessed; with none or several, there is no such state, and the initial values must sum to 1 (see Engine.init_fractions())
