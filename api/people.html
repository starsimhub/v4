people

people

The people in a sim (ss.People), lazy references to their properties (ss.person), and how they are made

People hold what every module shares, such as age, sex, and who is alive. In a compartmental run, each row is a group of people rather than an agent.

Used with: agents and compartments; declared and coded modules

LazyPeople

people.LazyPeople()

The people’s properties, before there are any people: ss.person.<name> is a lazy reference to the property <name> of each person (e.g. ss.person.age, ss.person.urban), checked when the sim is built

It can be used in a condition (ss.person.age < 15, for who=) and, as the person’s value, in a rate, a branch probability, or a result (expit(b0 + b1*ss.person.urban)); a condition in a rate is 1 for the people it holds for and 0 for the others (0.3*(ss.person.age > 65)).

Examples

p_use = expit(b0 + b_age*ss.person.age + b_urban*ss.person.urban)
kids = ss.person.age < 15

MadeOnUse

people.MadeOnUse()

One of the four fundamental arrays of ss.People, made on first use (see People.make_uids())

A descriptor rather than a branch of People.__getattr__(), so that a subclass with a __getattr__() of its own can’t hide it. It defines only __get__(), so once the arrays are made, the attribute in the instance’s __dict__ is found first and this costs nothing.

People

people.People(
    n_agents,
    age_data=None,
    extra_states=None,
    p_female=0.5,
    mock=False,
)

The people in a sim: their ages, sexes, who is alive, and the states that modules add to them; also how agents are born, die, and are counted

The sim usually makes this itself, from n_agents= (and total_pop=, the people they stand for). Give one yourself to give agents ages from data of your own (ss.People(n_agents, age_data=...)) or extra states; for the population of a place, use ss.population('Kenya'). In a compartmental run, each row is a group of people rather than an agent.

Parameters

Name Type Description Default
n_agents int the initial number of agents in the model required
age_data dataframe/series/array/str/ss.Dist the age distribution: a dataframe with columns age (the lower edge of each age bin) and value (the number or fraction of people in it), a series of values indexed by age, a two-column array, a CSV file with the dataframe’s columns, or a distribution of ages (default: the world’s ages). This gives agents ages; for age groups in a compartmental model, use disease.stratify(age={0: 0.3, 15: 0.6, 65: 0.1}) instead None
extra_states list more properties of each person, e.g. [ss.FloatArr('income')] (modules can also add them, with people.add_state()) None
p_female float the fraction of agents who are female 0.5
mock bool if True, link the people to a mock sim, so they can be used without one (for testing and debugging) False

Examples

ppl = ss.People(2000)
kids = ss.person.age < 15 # A lazy condition, for a sim run as agents or as compartments (see ss.person)

get_age_dist
people.People.get_age_dist(age_data)

The distribution that new agents’ ages are drawn from, made from age data

The data are a two-column array, a pandas series with age as the index and the number (or fraction) of people as the value, a dataframe with “age” and “value” columns, or the name of a CSV file with those columns, e.g.:

age      value
0      220.548
1      206.188
2      195.792
3      187.442

The ages are the lower edges of the bins, so ages within a bin are spread evenly. The last bin is as wide as the one before it; to set its upper edge, add a row with that age and a value of 0. Counts and fractions give the same distribution.

init_results
people.People.init_results()

Make the results of the people; called by Sim.init_results()

Each of the people’s own ss.BoolState states makes a result of the number in it (e.g. alive, the number alive); for a state that makes no result, use ss.BoolArr instead. There are also the flows of people who died and who left (died and emigrated; results.died.cum is the cumulative total).

With sim.pars.record_people=False, there are none of these (and record_states() and record_events() are skipped in the loop), which saves a little time and memory.

make_uids
people.People.make_uids()

Make the four fundamental arrays: UIDs for tracking agents, slots for tracking random numbers, AUIDs for tracking alive agents, and agents’ parents

They are made on first use rather than in __init__(), so that a People not yet in a sim (such as the copy a sim keeps of itself before it is initialized, for sim.new()) holds no arrays per agent. The slots read the UIDs, and the parents are all none, until one is set (see shared in ss.Arr), so they take no memory unless something (e.g. ss.Pregnancy, with fetuses as agents) sets them.

phase
people.People.phase(uids=None)

Each agent’s phase, in [0, 1), by UID: a time between steps, t, is taken at step floor(t + phase), so it is rounded up or down at random in proportion (2.3 steps is 2 for 70% of agents and 3 for the rest), keeping its mean, with no draws: both a time due in a disease written as code (ss.TimeArr.due()) and a dwell time of the agent engine. Spread evenly over the slots (so an agent has the same phase in every scenario), and shifted by the sim’s seed

Parameters
Name Type Description Default
uids uids the agents to give the phases of (worked out for them alone); by default, every agent’s, kept until agents are made None

request_death
people.People.request_death(uids, cause=None, hazard=None)

Request that agents die at this step; how a module kills agents

Use this rather than setting People.ti_dead directly, so that modules don’t overwrite each other’s deaths (e.g. a death set for the future overwriting one due now from another module). A module with a future time of death (e.g. after the course of a disease) keeps it itself, and calls this when the time comes, with itself as the cause.

The deaths happen after every module has stepped, but before the analyzers, so that analyzers can see and record the agents who died in this step.

Each person dies once, of one cause: if several modules request the death of the same person in the same step, one of them is chosen at random (whatever the order of the modules, with common random numbers): in proportion to the hazards of the claims if each gave one (hazard=), and otherwise each equally likely. The cause is kept in people.cause_of_death (see people.causes). A module counts its deaths after they are resolved, with people.died_of(module), so a death is counted once.

Parameters
Name Type Description Default
uids array the agents who die required
cause Module / str what they die of: a module (by its name) or a name (default: none) None
hazard float / array the hazard of this death, one number or one per agent (in any unit, the same for every module, e.g. per year), to weight the choice of cause among the claims on the same person in the step (e.g. dis.death.hazard(uids) for a declared transition) None

population

people.population(place, year=None, n_agents=None, revision=None)

A named population: the size, age structure, and sex ratio of a country or a US state

The data are the UN World Population Prospects, bundled with starsim_data (for a US state, the US Census for 2023, downloaded on first use: see ss.data.population()). The sim takes its population size (total_pop) from them, unless it is given one, and the split of an age stratification that is not given one, so a compartmental model can use a named population as well as agents can. Where the population came from is shown by sim.describe().

Parameters

Name Type Description Default
place str a country, by name or code (‘Kenya’, ‘KE’, ‘KEN’), or a US state (‘United States:Massachusetts’) required
year int the year (default: the year the sim starts, if it has dates; otherwise the year of the WPP revision, e.g. 2024); years between the decadal values are interpolated None
n_agents int the number of agents (default: the sim’s); giving it makes the model agent-based, as ss.People(n_agents) does None
revision str the WPP revision (default: the latest bundled) None

Returns

Name Type Description
An ss.People, with ppl.named saying where it came from

Examples

sim = ss.Sim(sir, people=ss.population('Kenya', year=2024), networks=ss.contacts('Kenya'))
ss.population('NG').named.total # The population of Nigeria in 2024
